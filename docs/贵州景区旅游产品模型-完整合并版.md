> 生成时间：2026-06-12  
> 遵守规则：陶总五大反对 + 禁用词语表 + 五步法框架  
> 结构：5维度判定框架 + 10产品卡片 + 5类型提炼 + AI匹配规则 + 交叉验证

| 目标 | 关键动作 | 衡量标准 |
|------|----------|----------|
| **目标1：产品可被AI识别和调用** | 每个产品定义清晰的消费区间、体力门槛、体验类型、季节适配标签 | 输入旅客画像后，AI能在1秒内完成匹配，准确率≥85% |

## 二、5维度判定框架（核心）

### 为什么只留5个？

旅客做决策时，真正卡住的不是信息不够，是**关键约束没对齐**。5个维度对应5个最刚性的决策卡点：想要什么（体验）、能不能去（门槛）、带谁去（人群）、什么时候去（窗口）、有什么坑（排除）。

**5个维度覆盖一个决策的完整闭环：想要什么 → 能不能去 → 带谁去 → 什么时候去 → 有什么坑。**

---

### 维度1：体验本质（Experience Core）

**判定标准（三选一，不可模糊）：**

| 体验类型 | 判定标准 | 包含产品 |
|----------|----------|----------|
| **自然震撼** | 以自然景观的体量/气势/稀有度为核心吸引力，首要感受是"壮观/惊叹" | 黄果树、梵净山、马岭河、织金洞、百里杜鹃、赤水丹霞 |
| **文化沉浸** | 以人文/历史/民族文化的深度参与为核心，首要感受是"了解/参与/共鸣" | 西江苗寨、镇远古镇、青岩古镇 |
| **生态放松** | 以环境清幽、低强度、恢复感为核心，首要感受是"放松/呼吸/慢下来" | 小七孔（部分）、赤水竹海、石阡温泉（未入10核心） |

**AI匹配规则：** 旅客出行目的直接对应体验类型。打卡观光→自然震撼；文化探索→文化沉浸；休闲度假→生态放松（本模型暂缺独立产品，需提示）。

---

### 维度2：投入门槛（Investment Threshold）

**定义：** 体力+时间+金钱，三者取最高档作为总门槛。

| 门槛等级 | 体力 | 时间 | 最低消费 | 判定逻辑 |
|----------|------|------|----------|----------|
| **低** | 步行≤1小时，无台阶 | 半日 | ≤150元 | 三要素全低 |
| **中** | 步行2-3小时，有台阶，可选辅助 | 1天 | 150-300元 | 任一要素达到中档 |
| **高** | 步行4小时+，高强度攀爬，无替代方案 | 2天+ | ≥300元 | 任一要素达到高档 |

---

### 维度3：人群宽容度（Audience Fit）

**定义：** 对同行人员组合的兼容程度。带娃/带老人是最刚性约束，比消费水平更优先。

| 等级 | 判定标准 | 可接待人群 |
|------|----------|-----------|
| **全年龄** | 无台阶/平路/轮椅可行/婴幼儿可推车 | 幼儿（0-6岁）、老人（65岁+）、轮椅、孕妇 |
| **中大龄友好** | 有台阶但密度低/有辅助设施/可分段完成 | 儿童（6岁+）、健康老人（60岁-）、普通成人 |
| **成人专属** | 高强度攀爬/安全风险/体力硬性要求 | 18-55岁健康成人 |

---

### 维度4：时间窗口刚性（Seasonal Constraint）

| 等级 | 判定标准 | 对AI匹配的影响 |
|------|----------|---------------|
| **全年无差** | 洞内/人文景点，季节不影响核心体验 | 任意季节推荐，无附加说明 |
| **季节加分** | 自然景区，非最佳季节仍可玩 | 非最佳季节可推荐，附加"X月去更佳"提示 |
| **季节打折** | 自然景区，非最佳季节核心体验明显下降 | 非最佳季节不推荐专程前往，附加预警 |
| **窗口期** | 仅极短时段有核心体验，错过=白去 | 非窗口期直接排除 |

---

### 维度5：反向排除（Exclusion Rule）

**定义：** 明确列出"不适合谁"。每个产品必须列出≥2条具体的、可验证的排除条件。说清不适合谁比适合谁更有价值。

**排除条件必须是客观标签（如"5岁以下儿童""轮椅使用者"），不能是主观感受（如"不喜欢走路的人"）。**

## 五、5类型提炼（基于5维度聚类）

**按"旅客决策模式"聚类，不是按行政区或资源类型。**

### 类型1：高门槛深度自然型

| 属性 | 详情 |
|------|------|
| **代表产品** | 梵净山、赤水丹霞 |
| **5维度共性** | 投入门槛高 + 人群成人专属/中大龄 + 时间窗口季节敏感 |
| **目标客群** | 25-45岁，体力充沛，无老人/幼儿，≥2天，舒适型起步 |
| **AI触发条件** | 体力充沛 + 无老人/幼儿 + 停留≥2天 + 季节在5-10月 |
| **组合建议** | 不与其他高门槛叠加，搭配类型3缓冲（如梵净山→镇远） |
| **核心风险** | 梵净山必须告知"金顶攀爬拉铁链，恐高者慎选" |

### 类型2：家庭友好自然奇观型

| 属性 | 详情 |
|------|------|

## 六、AI匹配规则（6步流程）

**输入：** 旅客画像（体验目的 + 体力/时间/预算 + 同行人员 + 出行季节）

**输出：** Top 3推荐 + 匹配理由 + 行程组合建议

### 匹配步骤

1. **体验目的 → 匹配类型**
   - 目的=打卡/震撼/冒险 → 类型1（若满足条件）或类型2（默认池）
   - 目的=文化/历史/民族 → 类型3
   - 目的=放松/疗愈 → 类型4（当前缺口，提示过渡方案）

2. **投入门槛校验**
   - 体力/时间/预算任一低于类型门槛 → 降级到类型2或3
   - 例：体力有限 → 排除类型1（梵净山/赤水）

3. **人群宽容度过滤**
   - 含幼儿/老人 → 排除类型1成人专属产品
   - 含孕妇/轮椅 → 仅保留类型2/3全年龄产品

4. **时间窗口刚性过滤**
   - 百里杜鹃非3月下旬-4月中旬 → 直接排除
   - 梵净山冬季 → 附加"能见度不稳定"预警
   - 织金洞/古镇类 → 任意季节无限制

5. **反向排除执行**
   - 命中任一排除条件 → 不进入候选池
   - 例：5岁儿童 → 排除黄果树（水帘洞不可）

6. **组合优化输出**
   - 多产品推荐时：类型交替（自然+文化），地理相邻（安顺/黔东南方向），强度递减（高→中→低）
   - 输出：Top 3推荐 + 每条匹配理由 + 1条反向排除提醒 + 行程组合建议

### 输出格式示例

```
推荐1：小七孔（匹配度：90%）
- 类型：类型2-家庭友好自然奇观
- 匹配理由：消费水平=舒适型，弹性区间完全覆盖
- 匹配理由：出行目的=亲子陪伴，该产品全年龄友好且有亲水体验
- 匹配理由：7月出行=该产品最佳季节，水量充沛
- 注意：需携带防滑鞋，浅水区需看护儿童

推荐2：西江苗寨（匹配度：85%）
- 类型：类型3-轻体力文化沉浸
- 匹配理由：文化体验互补，低体力适合家庭
- 匹配理由：夜景出片，适合亲子陪伴
- 注意：商业化成熟，非原生态，长桌宴需提前预约

推荐3：镇远古镇（匹配度：75%）
- 类型：类型3-轻体力文化沉浸
- 匹配理由：慢节奏缓冲，平衡前两日强度
- 匹配理由：零门槛，适合家庭漫步
- 注意：高端住宿选择有限，临江客栈为主

不推荐：梵净山
- 原因：类型1-高门槛深度自然，5岁儿童不符合成人专属门槛
- 替代：若孩子长大/单独成行，可优先推荐

行程组合建议：
Day1：小七孔（自然+亲水，中等强度）
Day2：西江苗寨（文化+夜景，低强度）
Day3：镇远古镇（缓冲+慢游，极低强度）
地理串联：黔南→黔东南，车程合理，类型交替不累。
```

### 异常处理

- 候选池为空 → 触发降级匹配：降低体力/消费要求，附加风险提示
- 画像不完整 → 追问缺失字段（"请确认出行季节，部分产品季节性极强"）
- 奢华型需求 → 如实告知"贵州以自然和文化为主，奢华度假设施非强项"，推荐西江高端民宿+私人包车
