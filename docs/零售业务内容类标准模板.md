## 六、模板使用指南

### 6.1 按客户等级选择模板

| 客户等级 | 服务准备阶段 | 触达阶段 | 登记阶段 |
|---------|------------|---------|---------|
| **S级** | 《客户诊断摘要》+《客户服务方案》 | 《沟通要点清单》 | 详细面谈纪要 |
| **A级** | 《客户诊断摘要》+《配置建议书》 | 《沟通要点清单》 | 标准触达记录 |
| **B级** | 《客户诊断摘要》+《沟通要点清单》 | 简要沟通要点 | 简要触达记录 |
| **C级** | 系统自动化 | 系统模板消息 | 系统自动化 |

### 6.2 按场景选择专用模板

| 场景 | 专用模板 | 配套通用模板 |
|------|---------|------------|
| 新客首触 | 《新客服务方案》 | 《客户诊断摘要》《沟通要点清单》 |
| 定期复盘 | 《配置建议书》 | 《客户诊断摘要》《沟通要点清单》 |
| 大额亏损 | 《持仓诊断报告》 | 《客户诊断摘要》《沟通要点清单》 |
| 产品配置 | 《产品配置方案书》 | 《客户诊断摘要》《沟通要点清单》 |
| 流失挽回 | 《客户挽回方案》 | 《客户诊断摘要》《沟通要点清单》 |
| 投诉处理 | 按投诉类型调用 | 《客户诊断摘要》《沟通要点清单》 |

### 6.3 模板生成方式

| 模板 | AI生成内容 | 人工确认内容 |
|------|-----------|------------|
| 客户诊断摘要 | 全部数据自动填充 | 关键发现和风险提示需人工确认 |
| 客户服务方案 | 现状摘要+策略建议 | 沟通要点+异议应对需人工调整 |
| 配置建议书 | 持仓分析+配置比例+产品匹配 | 客户目标+调整节奏需人工确认 |
| 沟通要点清单 | 标准框架+场景模块 | 异议应对+禁忌事项需人工补充 |
| 持仓诊断报告 | 亏损归因+结构分析 | 优化建议需人工确认 |
| 产品配置方案书 | 产品匹配+风险揭示 | 客户确认+合规审核需人工执行 |
| 客户挽回方案 | 流失归因+策略建议 | 挽回策略+触达安排需人工判断 |
| 新客服务方案 | 开户信息+推荐产品 | 首触安排+跟踪计划需人工确认 |
