# AI分析结果支持卡片示例（面向员工线下执行）

> 不是可填写的模板，而是AI自动生成的分析结果卡片
> 员工在线下执行动作前，直接获取AI分析结果作为支持
> 版本：v1.0
> 时间：2026-06-19

---

## 设计原则

1. **AI生成，员工直接看** — 不是空白模板，是填好数据的分析结果
2. **围绕主要维度** — 每个卡片只抓2-3个核心维度，不冗余
3. **支持线下执行** — 员工拿着卡片就能去触达客户
4. **一页纸原则** — 一个卡片对应一个动作，一目了然
