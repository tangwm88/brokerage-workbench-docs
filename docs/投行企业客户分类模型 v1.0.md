# 投行企业客户分类模型 v1.0

> **模型定位**：投行智能体的企业客户识别与分类入口，为后续产品模型、服务模型、角色动作模型的调用提供分类依据。
> 
> **服务目的**：让投行前台快速识别客户类型，自动匹配对应的资本服务方案和专业团队。
> 
> **目标角色**：投行前台承揽人员、业务支持中心组织者
> 
> **执行角色**：投行企业客户分类智能体

---

## 一、分类维度（5个本质维度）

每个维度必须满足：**可识别**（内容具体）、**可量化**（有客观数据）、**可调用**（无歧义，大模型自动匹配）、**卡片化**（独立可检索）。

### 维度1：企业规模梯次

| 分层 | 判定标准（满足任一即可） | 下一步动作 |
|------|------------------------|-----------|
| **头部企业** | 年营收 ≥ 100亿元；或总资产 ≥ 500亿元；或市值 ≥ 300亿元 | 调用「头部企业综合金融服务模型」，匹配资深团队，启动年度服务计划 |
| **中型企业** | 年营收 10-100亿元；或总资产 50-500亿元；或市值 30-300亿元 | 调用「中型企业成长融资模型」，匹配专项团队，评估融资窗口 |
| **成长企业** | 年营收 1-10亿元；或总资产 5-50亿元；或估值 3-30亿元 | 调用「成长企业股权融资模型」，匹配新兴产业团队，评估上市可行性 |
| **初创企业** | 年营收 < 1亿元；或总资产 < 5亿元；或估值 < 3亿元 | 调用「初创企业孵化服务模型」，匹配早期投资团队，建立跟踪档案 |

**数据来源**：企业年报、工商信息、Wind/同花顺数据库、券商内部客户系统

---

### 维度2：产业属性

| 产业大类 | 细分方向 | 产业链位置 | 下一步动作 |
|---------|---------|-----------|-----------|
| **先进制造** | 半导体、新能源、航空航天、高端装备 | 上游材料/中游制造/下游应用 | 调用「先进制造产业投行服务模型」，匹配产业研究团队 |
| **数字经济** | 软件信息、人工智能、大数据、云计算 | 基础设施/平台层/应用层 | 调用「数字经济产业投行服务模型」，匹配科技行业团队 |
| **消费升级** | 品牌零售、医疗健康、文化旅游 | 生产端/渠道端/服务端 | 调用「消费升级产业投行服务模型」，匹配消费行业团队 |
| **传统能源** | 煤炭、石油、电力、化工 | 开采/加工/输配/终端 | 调用「能源化工产业投行服务模型」，匹配能源行业团队 |
| **金融服务** | 银行、保险、证券、资管 | 持牌机构/金融科技/服务平台 | 调用「金融同业服务模型」，匹配金融团队 |
| **基础设施** | 交通、市政、公用事业、物流 | 投资/建设/运营 | 调用「基础设施融资服务模型」，匹配项目融资团队 |

**数据来源**：证监会产业分类标准、国民经济产业分类（GB/T 4754）、企业主营业务构成

---

### 维度3：资本需求类型

| 需求类型 | 触发信号 | 服务产品 | 下一步动作 |
|---------|---------|---------|-----------|
| **股权融资** | 企业有扩产计划、研发投入大、现金流紧张、有上市意向 | IPO、定增、配股、引入战略投资者 | 调用「股权融资产品模型」，启动上市可行性评估 |
| **债权融资** | 企业有项目投建、流动资金缺口、债务结构优化需求 | 公司债、企业债、ABS、可转债、银团贷款 | 调用「债权融资产品模型」，启动偿债能力分析 |
| **并购重组** | 企业有扩张战略、产业整合需求、资产剥离计划 | 借壳上市、产业并购、资产重整、跨境并购 | 调用「并购重组产品模型」，启动标的筛选 |
| **再融资** | 上市企业有资金缺口、项目投建、补充流动资金 | 定增、配股、可转债、公司债 | 调用「再融资产品模型」，启动发行窗口分析 |
| **财务顾问** | 企业有战略规划、股权架构调整、治理优化需求 | 战略规划、股权激励、私有化、分拆上市 | 调用「财务顾问服务模型」，启动诊断分析 |

**数据来源**：企业公告、融资历史、投建项目信息、管理层访谈纪要

---

### 维度4：企业发展阶段

| 阶段 | 判定特征 | 核心诉求 | 下一步动作 |
|------|---------|---------|-----------|
| **初创期** | 成立 < 3年，产品验证中，收入不稳定，未盈利 | 种子/天使融资、产业资源对接 | 调用「初创企业孵化服务模型」，纳入跟踪池 |
| **成长期** | 收入快速增长，市场份额扩大，开始盈利或接近盈利 | 股权融资、产能扩张、人才引进 | 调用「成长企业股权融资模型」，启动Pre-IPO评估 |
| **成熟期** | 收入稳定，市场地位稳固，盈利可预测 | 再融资、并购扩张、股东回报 | 调用「成熟企业综合服务模型」，启动年度服务计划 |
| **转型期** | 传统产业面临升级压力，或跨界进入新产业 | 并购重组、资产剥离、战略重塑 | 调用「企业转型顾问模型」，启动诊断分析 |
| **困境期** | 连续亏损、债务违约、流动性危机、重大诉讼 | 债务重组、破产重整、引入战投 | 调用「困境企业重组模型」，启动风险评估 |

**数据来源**：企业财务报表（近3年营收增长率、利润率、现金流）、经营动态、新闻舆情

---

### 维度5：企业性质

| 性质类型 | 判定标准 | 合规要点 | 下一步动作 |
|---------|---------|---------|-----------|
| **国有控股** | 国有资本持股 > 50%，或实际控制人为国资委/地方政府 | 国资审批程序、资产评估、进场交易、国资委备案 | 调用「国资企业服务模型」，同步国资合规检查清单 |
| **民营控股** | 自然人或民营企业持股 > 50%，无国资背景 | 实际控制人信用审查、关联交易披露、股权质押风险 | 调用「民营企业服务模型」，启动实控人风险评估 |
| **上市公司** | 已在A股/港股/美股等公开市场上市 | 信息披露合规、定期报告、关联交易、内幕信息管控 | 调用「上市公司服务模型」，同步信披合规检查 |
| **非上市公众公司** | 新三板挂牌、区域股权市场挂牌、股东人数 > 200人 | 定向发行合规、股东人数监控、信息披露要求 | 调用「非上市公众公司服务模型」，启动合规评估 |
| **外资企业** | 境外资本控股，或主要运营地在境外 | 外商投资准入、跨境资金流动、外汇管理、国际会计准则 | 调用「外资企业服务模型」，启动跨境合规检查 |

**数据来源**：工商股权结构、实际控制人穿透、上市状态、国资标识

## 二、分类调用规则

企业客户分类完成后，按以下规则自动调用后续模型：

```
客户分类完成
    │
    ├─→ 维度1（规模）+ 维度2（产业）→ 匹配「专业团队」
    │
    ├─→ 维度3（资本需求）→ 调用「产品模型」
    │       ├─ 股权融资 → 股权融资产品模型
    │       ├─ 债权融资 → 债权融资产品模型
    │       ├─ 并购重组 → 并购重组产品模型
    │       ├─ 再融资 → 再融资产品模型
    │       └─ 财务顾问 → 财务顾问服务模型
    │
    ├─→ 维度4（发展阶段）→ 调整「服务策略」
    │       ├─ 初创/成长 → 侧重融资可行性、上市路径
    │       ├─ 成熟 → 侧重再融资效率、股东回报
    │       ├─ 转型 → 侧重并购重组、战略重塑
    │       └─ 困境 → 侧重风险评估、重组方案
    │
    └─→ 维度5（企业性质）→ 加载「合规检查清单」
            ├─ 国有控股 → 国资审批流程
            ├─ 民营控股 → 实控人风险检查
            ├─ 上市公司 → 信披合规检查
            ├─ 非上市公众公司 → 定向发行合规
            └─ 外资企业 → 跨境合规检查
```

以下组合验证分类的完整性和一致性：

| 规模 | 产业 | 资本需求 | 发展阶段 | 企业性质 | 自动输出 |

## 四、自检清单

### 陶总五大反对检查

| 反对项 | 自检结果 | 说明 |
|--------|---------|------|
| 反对讲意义不讲模型 | ✅ 通过 | 本模型直接输出5个维度、分层标准、调用规则，无空泛描述 |
| 反对流程化线性化 | ✅ 通过 | 5个维度是独立可调用卡片，非线性流程，根据客户特征动态组合 |
| 反对角色混乱 | ✅ 通过 | 服务目的、目标角色、执行角色已明确标注 |
| 反对拍脑袋甩锅AI | ✅ 通过 | 每个分层有客观数据标准（营收/资产/市值），人可复核 |
| 反对技术自说自话 | ✅ 通过 | 从投行前台承揽角色出发，未涉及系统功能描述 |

### 原子模型设计标准检查

- ✅ **可识别**：每个维度分层内容具体（如"年营收 ≥ 100亿元"）
- ✅ **可量化**：全部具体化，无模糊表述（如"头部/中型/成长/初创"有明确数值边界）
- ✅ **可调用**：无修饰形容词，无歧义，大模型可根据企业数据自动匹配分层
- ✅ **卡片化**：每个维度独立成卡，可单独识别、检索、组合

## 五、使用说明

### 输入
企业基础信息：
- 工商注册信息（成立时间、注册资本、股权结构）
- 最近3年财务报表（营收、利润、资产、现金流）
- 上市状态及融资历史
- 主营业务描述及产业分类
- 近期公告及新闻动态

### 输出
- 企业分类结果（5个维度的分层定位）
- 自动匹配的专业团队
- 调用的产品模型清单
- 加载的合规检查清单
- 下一步动作建议

### 更新触发条件
- 企业年报发布后（年度更新）
- 企业发生并购重组、重大投资（事件触发更新）
- 企业上市状态变更（状态变更触发更新）
- 分类准确率低于80%（质量触发更新）
