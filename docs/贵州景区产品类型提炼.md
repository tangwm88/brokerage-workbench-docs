# 贵州景区产品类型提炼（基于5维度模型分析）

> 基于5维度速查表交叉分析，将10个核心景区聚类为5种产品类型  
> 每种类型有明确的特征画像、目标客群、AI推荐策略、互补组合建议  
> 版本：v1.0

---

## 提炼逻辑

**不是按景区行政区或资源类型分，而是按"旅客决策模式"分。**

两个旅客都想去自然景区，但一个带5岁娃、一个徒步爱好者，他们的决策逻辑完全不同。类型划分的依据是：**5维度上的共性特征 → 共同的目标客群 → 共同的AI推荐策略。**

## 类型1：高门槛深度自然型

### 5维度特征画像

| 维度 | 特征 | 为什么是这个档 |
|------|------|---------------|
| 体验本质 | 自然震撼 | 核心吸引力是"稀缺+震撼"，不是休闲放松 |
| 投入门槛 | **高** | 梵净山体力和消费双高，赤水丹霞时间成本高（需2-3天） |
| 人群宽容度 | 成人专属 / 中大龄 | 梵净山60岁+老人官方不建议登顶，赤水丹霞单日步行量偏大 |
| 时间窗口 | 季节打折 / 季节加分 | 梵净山冬季能见度不稳，赤水丹霞4-10月最佳 |
| 核心排除 | 体力差、时间<2天、带幼儿/老人 | 三项硬性排除 |

### 代表产品

| 产品 | 核心差异点 | 适合什么场景 |
|------|-----------|-------------|
| **梵净山** | 体力挑战+仙气+佛教文化 | 想要"挑战自我+拍出硬照"的旅客 |
| **赤水丹霞** | 慢游+世界遗产+地质科普 | 想要"深度自然+不赶时间"的旅客 |

### 目标客群画像

- 年龄：25-45岁
- 体力：充沛或中等偏上
- 出行目的：挑战冒险、深度自然、摄影
- 同行人员：无老人/幼儿/孕妇，最好是成人结伴或独行
- 时间预算：≥2天（赤水需3天）
- 消费水平：舒适型起步（梵净山索道+门票280元刚性，赤水多景点包车成本）

### AI推荐策略

**触发条件（必须全部满足）：**
1. 体力=充沛 或 中等偏上
2. 无老人/幼儿同行
3. 停留时间≥2天（梵净山）或≥3天（赤水）
4. 出行季节在5-10月（梵净山）或4-10月（赤水）

**优先级：** 高（如果满足条件，通常是旅客的核心诉求）

**组合建议：** 不与其他高门槛产品叠加（梵净山+赤水=体力耗尽），建议搭配低门槛文化产品缓冲（如梵净山后去镇远古镇休息）。

**风险预警：** 梵净山必须提前告知"金顶攀爬需拉铁链，恐高者/膝盖不好者慎选"。

## 类型2：家庭友好自然奇观型

### 5维度特征画像

| 维度 | 特征 | 为什么是这个档 |
|------|------|---------------|
| 体验本质 | 自然震撼 | 核心吸引力是"视觉奇观+亲子共赏" |
| 投入门槛 | 中 / 低 | 黄果树/马岭河/织金洞中等，小七孔/百里杜鹃低 |
| 人群宽容度 | 全年龄 / 中大龄 | 小七孔和百里杜鹃全年龄，织金洞和黄果树中大龄 |
| 时间窗口 | 季节加分 / 全年无差 / 窗口期 | 百里杜鹃窗口期极窄，其余季节敏感 |
| 核心排除 | 特定安全条件（非体力门槛） | 黄果树婴幼儿不可、马岭河恐高不可、织金洞幽闭恐惧不可 |

### 代表产品

| 产品 | 核心差异点 | 安全注意 |
|------|-----------|----------|
| **小七孔** | 全年龄+亲水+观光车覆盖 | 浅水区安全，但需防滑 |
| **百里杜鹃** | 全年龄+老人极友好+窗口期 | 花粉过敏者注意 |
| **织金洞** | 全年可去+避暑+地质科普 | 幽闭恐惧/体力极差者不可 |
| **黄果树** | 必打卡+贵州名片+性价比高 | 6岁以下不可进水帘洞 |
| **马岭河** | 小众+瀑布群+地质奇观 | 谷底湿滑+栈道悬空 |

### 目标客群画像

- 年龄：30-50岁（父母）+ 6-14岁（儿童）
- 体力：中等或有限
- 出行目的：亲子陪伴、打卡观光、家庭度假
- 同行人员：核心特征是"带儿童"，可能含老人
- 时间预算：1-3天（单个产品）
- 消费水平：经济型到舒适型（贵州自然景区整体性价比高）

### AI推荐策略

**触发条件（满足任一即可）：**
1. 同行人员含6-14岁儿童
2. 出行目的=亲子陪伴
3. 体力=有限 或 中等

**优先级排序（按季节+人群）：**
- 7-8月暑假：小七孔（亲水） > 黄果树（必打卡） > 织金洞（避暑）
- 3-4月花期：百里杜鹃（窗口期，仅20天）→ 唯一推荐
- 冬季：织金洞（全年无差） > 小七孔（幽静） > 黄果树（打折但可去）
- 带老人+儿童：优先百里杜鹃、小七孔（全年龄）
- 仅带儿童（无老人）：可增加黄果树、织金洞、马岭河

**组合建议：** 自然产品之间可按地理相邻组合：
- 安顺方向：黄果树 + 织金洞（2天）
- 黔南方向：小七孔（1天）+ 茂兰/大七孔（扩展）
- 毕节方向：百里杜鹃（花期）+ 织金洞（1.5天）

**风险预警：** 必须根据同行人员年龄排除不可去的：带5岁以下→排除黄果树水帘洞、马岭河；带老人腿脚不便→排除黄果树（台阶多）、马岭河（湿滑）。

## 类型3：轻体力文化沉浸型

### 5维度特征画像

| 维度 | 特征 | 为什么是这个档 |
|------|------|---------------|
| 体验本质 | 文化沉浸 | 核心吸引力是"人文参与+历史感+民族风情" |
| 投入门槛 | **低** | 三个古镇体力门槛均低，消费弹性差异大（西江可奢华） |
| 人群宽容度 | 全年龄 | 古镇漫步零门槛，电瓶车覆盖，适合所有人群 |
| 时间窗口 | 全年无差 | 不受季节影响，民俗节日是加分项非必需 |
| 核心排除 | 追求原生态/只看自然风光/专程远道 | 商业化程度和体验深度是主要排除点 |

### 代表产品

| 产品 | 核心差异点 | 消费弹性 | 商业化程度 |
|------|-----------|----------|-----------|
| **西江千户苗寨** | 夜景之王+苗族文化全体验+住宿两极化 | 全区间（110元-3000元+） | 高（成熟景区） |
| **镇远古镇** | 两千年历史+安静+比凤凰人少 | 经济型-舒适型（性价比极高） | 中（生活化古镇） |
| **青岩古镇** | 美食+半日游+最低门槛 | 经济型（极致性价比） | 中高（周末人多） |

### 目标客群画像

- 年龄：全年龄（20-60岁均有）
- 体力：有限或中等（低体力偏好）
- 出行目的：文化探索、休闲度假、打卡出片、美食
- 同行人员：可含老人/幼儿/孕妇（全年龄友好）
- 时间预算：0.5-2天
- 消费水平：全区间（西江可奢华，镇远/青岩平价）

### AI推荐策略

**触发条件（满足任一即可）：**
1. 出行目的=文化探索
2. 体力=有限
3. 同行人员含老人/幼儿/孕妇
4. 自然景区门票预算不足（青岩10元、镇远免费古城）

**优先级排序（按消费水平+偏好）：**
- 预算有限+文化兴趣一般：青岩（半日缓冲）或镇远（1-2天慢游）
- 预算充足+想要深度体验：西江（住高端民宿+长桌宴+夜景）
- 体力有限+带老人：镇远（安静+临江+零门槛）
- 追求原生态+反感商业化：三个都不推荐（需扩展朗德/季刀等次级苗寨）

**组合建议：** 文化产品常作为自然产品的"缓冲剂"：
- 黄果树（累）→ 镇远（休息）
- 梵净山（累）→ 西江（体力恢复+文化体验）
- 小七孔（自然）→ 西江（文化互补）

**风险预警：** 西江商业化程度高，必须提前告知"非原生态，是成熟景区"。青岩周末贵阳本地人涌入，建议工作日前往。

## 类型4：生态放松型（当前缺口）

### 5维度特征画像

| 维度 | 特征 | 为什么是缺口 |
|------|------|-------------|
| 体验本质 | 生态放松 | 贵州以"自然震撼+文化沉浸"为主，缺少以"放松恢复"为核心定位的产品 |
| 投入门槛 | 低 | 放松型产品需要低体力门槛 |
| 人群宽容度 | 全年龄 | 放松型产品需要全年龄兼容 |
| 时间窗口 | 全年无差 | 放松不受季节影响 |
| 核心排除 | 追求刺激/打卡 | 与自然震撼型客群互斥 |

### 代表产品（建议补充）

| 产品 | 核心差异点 | 当前状态 |
|------|-----------|----------|
| **荔波茂兰** | 原始森林+徒步+溶洞+比小七孔更野 | 已在荔波区域，可与小七孔组合 |
| **赤水竹海** | 竹林+瀑布+负氧离子+极度安静 | 已在赤水区域，可与丹霞组合 |
| **石阡温泉** | 温泉+古镇+慢节奏 | 独立产品，铜仁方向 |
| **万峰林（兴义）** | 喀斯特峰林+田园+骑行+民宿 | 与马岭河同属兴义区域 |

### 目标客群画像

- 年龄：30-55岁（职场压力人群）+ 银发族
- 体力：有限或中等（偏好低强度）
- 出行目的：休闲度假、疗愈、逃离城市、慢节奏
- 同行人员：可含老人/幼儿
- 时间预算：2-3天（放松需要时间沉淀）
- 消费水平：舒适型到品质型（放松型产品通常住宿决定体验）

### AI推荐策略

**触发条件：**
1. 出行目的=休闲度假 且 明确表达"想要放松/不想太累"
2. 体力=有限 且 拒绝自然震撼型（如明确说"不想爬山/走太多"）

**当前问题：** 10个核心产品中缺乏生态放松型独立产品。小七孔和赤水丹霞有部分放松属性，但核心定位仍是自然震撼。

**过渡方案：**
- 当旅客明确要放松时，推荐镇远古镇（文化沉浸中最接近放松的）或 西江高端民宿（住宿体验导向）
- 附加说明："贵州以自然奇观和民族文化为主，纯放松度假产品建议考虑茂兰/竹海/温泉等延伸选项"

**扩展建议：** 将茂兰、竹海、温泉、万峰林纳入产品库，作为类型4的正式成员。

## 类型5：过渡/缓冲型

### 5维度特征画像

| 维度 | 特征 | 为什么单独列一类 |
|------|------|---------------|
| 体验本质 | 文化沉浸（轻量） | 不是核心目的地，是行程的"过渡段" |
| 投入门槛 | **极低** | 半日、10元门票、公交可达 |
| 人群宽容度 | 全年龄 | 零门槛，适合任何人群 |
| 时间窗口 | 全年无差 | 不受季节影响 |
| 核心排除 | 专程远道而来 | 只适合作为附加项，不适合作为行程核心 |

### 代表产品

| 产品 | 定位 | 典型使用场景 |
|------|------|-------------|
| **青岩古镇** | 贵阳周边半日游 | 到达贵阳首日/离开前最后半日/自然景区之间的缓冲日 |

### 目标客群画像

- 所有旅客均可，但**不应作为专程目的地**
- 典型场景：下午到达贵阳，晚上航班，中间有3-4小时空档

### AI推荐策略

**不主动推荐，只作为缓冲填充：**
- 当行程有空档（如到达日只有半天）→ 自动推荐青岩
- 当旅客说"明天离开贵阳，还有半天时间"→ 推荐青岩
- 当黄果树/小七孔行程后需要低强度过渡日→ 推荐青岩或镇远

**组合规则：** 类型5产品不单独成行程，只作为首尾或缓冲：
- 到达日：青岩（半日适应）
- 自然景区日：黄果树/小七孔（核心）
- 离开日：青岩（半日收尾）

## 类型组合策略（行程设计逻辑）

**核心原则：高强度+低强度交替，自然+文化互补。**

### 推荐组合模式

| 天数 | 推荐组合 | 类型配比 | 为什么这样配 |
|------|----------|----------|-------------|
| **2天** | 类型2（小七孔）+ 类型3（西江） | 自然+文化 | 强度互补，地理相邻（黔东南方向） |
| **3天** | 类型2（黄果树）+ 类型2（织金洞）+ 类型3（镇远） | 自然+自然+文化缓冲 | 黄果树+织金洞同方向（安顺），镇远缓冲 |
| **4天** | 类型1（梵净山）+ 类型3（镇远）+ 类型2（小七孔）+ 类型3（西江） | 挑战+缓冲+自然+文化 | 梵净山后必须接低强度（镇远），再转自然+文化 |
| **5天** | 类型2（黄果树）+ 类型2（织金洞）+ 类型3（西江）+ 类型3（镇远）+ 类型2（小七孔） | 自然+文化混合 | 经典大环线，类型交替不累 |
| **7天+** | 全类型覆盖，加入类型4（茂兰/竹海） | 自然+文化+放松 | 深度游，需补充类型4产品 |

### 避免组合

| 组合 | 为什么避免 | 替代方案 |
|------|----------|----------|
| 类型1+类型1（梵净山+赤水） | 连续高体力，旅客崩溃 | 中间插入类型3（镇远）缓冲 |
| 类型2+类型2+类型2（黄果树+小七孔+马岭河） | 自然奇观疲劳，缺乏文化调剂 | 拆分为自然+文化交替 |
| 类型5单独成行程 | 青岩半天不值得专程 | 作为类型2/3的附加项 |

## 类型与AI开发的关系

### 产品类型 → 智能体调用规则

**每个类型对应一个"推荐策略模板"，AI根据旅客画像匹配类型，再调用该类型下的具体产品。**

```
旅客画像输入
  → 判断适合什么类型（基于5维度匹配）
    → 类型1：高门槛深度自然 → 检查体力/时间/人群/季节 → 推荐梵净山/赤水
    → 类型2：家庭友好自然 → 检查季节/儿童年龄/安全条件 → 推荐小七孔/黄果树/织金洞/百里杜鹃/马岭河
    → 类型3：轻体力文化 → 检查预算/商业化接受度 → 推荐西江/镇远/青岩
    → 类型4：生态放松 → 检查"是否明确要放松" → 当前缺口，提示扩展
    → 类型5：过渡缓冲 → 检查行程空档 → 自动填充青岩
  → 类型内产品排序（按季节/预算/偏好）
  → 多类型组合优化（高强度+低强度交替）
  → 输出Top 3推荐 + 行程组合建议
```

## 核心洞察

1. **贵州产品结构的"偏科"：** 自然震撼（类型2）和文化沉浸（类型3）丰富，但高门槛深度自然（类型1）仅2个，生态放松（类型4）几乎空白。这意味着AI遇到"想要放松"的旅客时，会面临推荐困难——现有产品都不是为放松设计的。

2. **类型1是贵州的"差异化王牌"：** 梵净山和赤水丹霞在全国有独特性，但门槛过高导致客群窄。AI推荐时应该"精准推送"而不是"广撒网"——满足条件的旅客，类型1应该排第一；不满足条件的，不要硬推。

3. **类型2是"现金牛"：** 覆盖家庭客群最大，产品数量最多（5个），消费门槛低，季节敏感。AI应该把这个类型作为默认推荐池，然后根据细分条件（季节、儿童年龄、安全条件）做二次筛选。

4. **类型3的消费弹性被低估：** 西江苗寨可以奢华到3000元+/晚，也可以经济到100元/晚。同一个类型下，消费水平决定的是"住哪里"而不是"去不去"。AI匹配时，类型3的门槛不是钱，是商业化接受度。

5. **类型5是被忽略的"行程粘合剂"：** 很多行程设计失败是因为空档没填好。AI应该把类型5作为自动填充项，而不是等旅客问"还有半天怎么办"。
