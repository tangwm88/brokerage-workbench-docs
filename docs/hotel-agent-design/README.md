# 酒店智能体方案（总体概述）

## 一、做这个方案的目的

酒店智能体 = 1个**系统大脑** + 1套**客户随身帮手** + 1套**酒店员工工作台** + 1套**数据看板**。客户和服务人员共用同一张信息底牌，减少信息传错，加速服务响应，提升客户体验。

## 二、五步法方法论（贯穿全方案）

每条线都按这5步走：

| 步骤 | 名字 | 说明 |
|------|------|------|
| 1 | 看清人是谁 | 识别角色、客户类型、服务需求 |
| 2 | 摸清要干啥 | 拆解任务、动作、事件 |
| 3 | 找到谁来干 | 匹配执行人/AI工具/自动引擎 |
| 4 | 定好完成标准 | 输出什么、多长时间完成、怎么算好 |
| 5 | 收尾反馈 | 结果记录、客户评价、数据入档 |

## 三、角色体系（三类人）

### 1. 服务接收方（客户）

| 客户类型 | 核心需求 | 服务偏好 |
|----------|----------|----------|
| 商务差旅 | 快、准、静 | 自助优先、时间敏感 |
| 家庭度假 | 宽、安、趣 | 亲子友好、空间舒适 |
| 情侣休闲 | 私、美、暖 | 氛围感、隐私保护 |
| 会议团队 | 齐、专、稳 | 批量管理、会议室配套 |
| 长住 | 惯、省、熟 | 熟悉感、成本控制 |
| VIP/老人/儿童/残障 | 细、护、达 | 特殊照顾、无障碍 |

### 2. 服务交付方（酒店员工）

| 岗位 | 服务客户 | 核心动作 |
|------|----------|----------|
| 前台接待员 | 所有客户 | 办理入住/退房、问询应答 |
| 客房服务员 | 入住客户 | 房间打扫、用品补充、问题上报 |
| 餐饮服务 | 所有客户 | 点餐/送餐、餐厅服务 |
| 管家/客服 | 高端/特殊客户 | 一对一服务、需求协调 |
| 工程维修 | 所有客户 | 设备维修、巡检 |
| 运营组织者（值班经理/管理层） | 内部团队 | 调度、监控、决策 |

### 3. 运营组织者（系统+人）

- 值班经理：当班期间看全局、处理升级事项
- 管理层：看数据、定规则、优化服务
- 智能体系统：自动推送任务、自动预警、辅助决策

## 六、设计原则（6条铁律）

1. **先说人，再谈事**——角色定了，动作跟着角色走
2. **动词开头，名词跟上**——不用虚词，不绕弯子
3. **每件事有起点、有终点、有标准**——不埋坑、不留尾
4. **AI能自动的，不让人手动**——减少重复点击
5. **客户和服务员看同一页数据**——消灭信息差
6. **所有数据入档，下次复用**——客户再来，服务升级

## 七、项目术语（不用黑话）

| 不用 | 改用 |
|------|------|
| 场景 | 客户类型 + 服务阶段 |
| 流程 | 规定动作（步骤清单） |
| 逻辑 | 触发条件 + 判断规则 |
| 话术 | 提示词（工程级 + 交互级） |
| 架构 | 系统结构（三件套） |
| 策略 | 选择规则（如果A则B） |
