# 投行企业客户分类模型 v1.1（发散-收敛版）

> **模型定位**：投行智能体的企业客户识别与分类入口。先多视角发散分类，再提炼汇总合并，形成可调用、可检索的客户分类体系。
> 
> **设计方法**：客观分类 → 提炼主维度 → 标准化建模 → 动态调用
> 
> **服务目的**：让投行前台快速识别客户类型，自动匹配资本服务方案和专业团队。
> 
> **目标角色**：投行前台承揽人员、业务支持中心组织者
> 
> **执行角色**：投行企业客户分类智能体

---

## 第一部分：多视角发散分类（第一阶段：穷尽视角）

以下从10个不同视角对企业客户进行分类。**每个视角独立成卡**，先不合并、不删减，确保覆盖面完整。

---

### 视角1：财务规模视角

| 分层 | 判定标准（满足任一即可） |
|------|------------------------|
| 超大型 | 年营收 ≥ 500亿元；或总资产 ≥ 2000亿元；或市值 ≥ 1000亿元 |
| 大型 | 年营收 100-500亿元；或总资产 500-2000亿元；或市值 300-1000亿元 |
| 中型 | 年营收 10-100亿元；或总资产 50-500亿元；或市值 30-300亿元 |
| 成长型 | 年营收 1-10亿元；或总资产 5-50亿元；或估值 3-30亿元 |
| 小微型 | 年营收 < 1亿元；或总资产 < 5亿元；或估值 < 3亿元 |

**数据来源**：企业年报、审计报告、Wind/同花顺数据库

### 视角3：资本需求视角

| 需求类型 | 触发信号 | 典型产品 |
|---------|---------|---------|
| 首发上市 | 有上市意向、合规基础较好、业绩达到门槛 | IPO、借壳上市、SPAC |

### 视角4：发展阶段视角

| 阶段 | 判定特征 | 核心诉求 |
|------|---------|---------|
| 初创期 | 成立 < 3年，产品验证中，收入不稳定，未盈利 | 种子/天使融资、产业资源对接、商业模式验证 |
| 成长期 | 收入快速增长（年增速 > 30%），市场份额扩大，开始盈利或接近盈利 | 股权融资、产能扩张、人才引进、Pre-IPO准备 |
| 成熟期 | 收入稳定（增速 5-15%），市场地位稳固，盈利可预测 | 再融资、并购扩张、股东回报、市值管理 |
| 转型期 | 传统产业面临升级压力，或跨界进入新产业，营收波动大 | 并购重组、资产剥离、战略重塑、新业务孵化 |
| 困境期 | 连续2年亏损、债务违约、流动性危机、重大诉讼 | 债务重组、破产重整、引入战投、资产保全 |
| 退出期 | 实控人有退出意向、股东结构僵化、行业天花板明显 | 股权转让、并购退出、私有化、清算 |

**数据来源**：企业财务报表（近3年营收增长率、利润率、现金流）、经营动态

### 视角5：所有制性质视角

| 性质类型 | 判定标准 | 特殊程序 |
|---------|---------|---------|
| 央企控股 | 国务院国资委直接管理企业控股 | 国资委审批、资产评估、进场交易 |
| 地方国企 | 省/市/区国资委或地方政府控股 | 地方国资审批、资产评估、进场交易 |
| 民营控股 | 自然人或民营企业控股，无国资背景 | 实控人信用审查、关联交易披露 |
| 外资控股 | 境外资本控股，或主要运营地在境外 | 外商投资准入、跨境资金、外汇管理 |
| 混合所有制 | 国资与民资共同控股，股权结构多元 | 兼顾国资程序与市场化运作 |
| 公众持股 | 无单一控股股东，股权分散 | 股东大会决策、信息披露合规 |

**数据来源**：工商股权结构、实际控制人穿透、国资标识

### 视角6：上市状态视角

| 状态 | 判定标准 | 合规要点 |
|------|---------|---------|
| A股主板上市 | 在上交所/深交所主板挂牌 | 信息披露、定期报告、关联交易、内幕信息管控 |
| A股创业板/科创板上市 | 在创业板/科创板挂牌 | 信息披露、研发投入披露、特殊股权结构 |
| 港股上市 | 在香港联交所挂牌 | 港交所规则、跨境披露、外汇管理 |
| 美股上市 | 在纽交所/纳斯达克挂牌 | SEC规则、跨境审计、VIE架构合规 |
| 新三板挂牌 | 在全国股转系统挂牌 | 定向发行合规、信息披露、层级管理 |
| 非上市公众公司 | 未挂牌但股东人数 > 200人 | 定向发行合规、股东人数监控 |

### 视角8：信用等级视角

| 等级 | 判定标准 | 风险信号 |
|------|---------|---------|
| AAA级 | 信用评级AAA，无违约记录，财务状况稳健 | — |
| AA级 | 信用评级AA，偶有波动，整体健康 | 需关注行业周期 |
| A级 | 信用评级A，存在一定风险因素 | 杠杆率偏高、现金流紧张 |
| BBB级 | 信用评级BBB，风险因素较多 | 债务压力大、盈利下滑 |
| 投机级 | 信用评级BB及以下，或已有违约记录 | 债务违约、流动性危机、重大诉讼 |
| 无评级 | 无公开信用评级，信息不透明 | 信息缺失、尽职调查成本高 |

**数据来源**：外部信用评级（中诚信、联合、大公等）、内部评级模型、违约记录

### 视角9：客户生命周期视角（与投行关系深度）

| 阶段 | 特征 | 服务策略 |
|------|------|---------|
| 潜在客户 | 有业务需求信号，尚未建立正式合作 | 主动触达、需求识别、建立联系 |
| 初次合作 | 首次开展投行项目，关系建立中 | 高标准交付、建立信任、挖掘后续需求 |
| 持续合作 | 已开展2个以上项目，关系稳定 | 定期回访、交叉销售、深化服务 |
| 战略客户 | 年度合作金额大、多产品覆盖、高层互动频繁 | 专属团队、定制化服务、年度服务计划 |
| 流失预警 | 合作频率下降、转向竞品、重大负面事件 | 原因分析、挽回方案、高层沟通 |

**数据来源**：CRM系统、项目历史、合作金额、互动记录

---

### 视角10：战略重要性视角

| 等级 | 判定标准 | 资源配置 |
|------|---------|---------|
| 核心战略客户 | 行业龙头、品牌效应强、能带来示范效应、长期合作价值大 | 高管挂帅、专属团队、优先资源、定制化方案 |
| 重要客户 | 细分市场领先、合作稳定、有一定影响力 | 资深团队、标准化+个性化服务 |
| 一般客户 | 偶发性合作、标准化需求、影响力有限 | 标准化服务、流程化交付 |
| 储备客户 | 有潜力但尚未合作、需长期培育 | 纳入跟踪池、定期触达、需求培育 |

**数据来源**：行业地位、品牌影响力、合作历史、潜在价值评估

## 第二部分：提炼汇总合并（第二阶段：收敛精炼）

从上述10个视角中，提炼出**5个核心维度**作为智能体的主分类框架。其余视角作为**辅助标签**，在调用时附加使用。

### 合并逻辑

| 核心维度 | 合并来源 | 合并方式 |
|---------|---------|---------|
| **规模梯次** | 视角1（财务规模）+ 视角8（信用等级） | 规模为主，信用等级作为风险调整系数 |
| **产业属性** | 视角2（产业属性）+ 视角7（区域属性） | 产业为主，区域作为辅助标签 |
| **资本需求** | 视角3（资本需求） | 独立保留，作为产品调用主入口 |
| **发展阶段** | 视角4（发展阶段）+ 视角6（上市状态） | 发展阶段为主，上市状态作为资本需求的辅助判定 |
| **关系深度** | 视角9（客户生命周期）+ 视角10（战略重要性）+ 视角5（所有制性质） | 关系深度和战略重要性合并为"客户价值分层"，所有制作为合规标签 |

## 第四部分：多维度交叉分类矩阵（最终输出）

企业客户的最终分类是**5个核心维度的交叉组合**，形成多维分类标签。

### 分类输出示例

| 企业 | 规模-风险 | 产业-区域 | 资本需求 | 发展阶段-上市 | 价值-合规 | 自动调用 |

## 第五部分：动态调用规则

```
客户信息录入
    │
    ├─→ 10个视角分别打标签（发散）
    │       ├─ 财务规模 → 规模标签
    │       ├─ 产业属性 → 产业标签
    │       ├─ 资本需求 → 需求标签
    │       ├─ 发展阶段 → 阶段标签
    │       ├─ 所有制 → 合规标签
    │       ├─ 上市状态 → 状态标签
    │       ├─ 区域属性 → 区域标签
    │       ├─ 信用等级 → 风险标签
    │       ├─ 生命周期 → 关系标签
    │       └─ 战略重要性 → 价值标签
    │
    ├─→ 5个核心维度提炼合并（收敛）
    │       ├─ 规模+信用 → 规模-风险分层
    │       ├─ 产业+区域 → 产业-区域标签
    │       ├─ 资本需求 → 需求类型（独立）
    │       ├─ 阶段+上市 → 发展阶段-上市状态
    │       └─ 关系+价值+所有制 → 客户价值-合规标签
    │
    └─→ 交叉组合输出（调用）
            ├─ 规模-风险 → 匹配服务等级（资源投入）
            ├─ 产业-区域 → 匹配专业团队
            ├─ 资本需求 → 调用产品模型
            ├─ 发展阶段 → 调整服务策略
            └─ 价值-合规 → 加载合规清单 + 配置资源
```

## 第七部分：使用说明

### 输入
企业基础信息：
- 工商注册信息（成立时间、注册资本、股权结构、注册地址）
- 最近3年财务报表（营收、利润、资产、现金流）
- 上市状态及融资历史
- 主营业务描述及产业分类
- 近期公告及新闻动态
- 外部信用评级（如有）
- 与投行合作历史（如有）

### 输出
- 10个视角的独立标签
- 5个核心维度的合并分类
- 多维度交叉分类结果
- 自动匹配的专业团队
- 调用的产品模型清单
- 加载的合规检查清单
- 服务资源配置建议
- 下一步动作建议

### 更新触发条件
- 企业年报发布后（年度更新）
- 企业发生并购重组、重大投资（事件触发更新）
- 企业上市状态变更（状态变更触发更新）
- 企业信用评级调整（评级变更触发更新）
- 分类准确率低于80%（质量触发更新）
