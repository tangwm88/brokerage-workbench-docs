# 酒店客房产品模型 v1.1 — 标杆蒸馏版

> 基于五步法 Step 2 标杆分析 + Step 4 模型定义
> 标杆来源：国际连锁（万豪/希尔顿）+ 国内标杆（亚朵）+ 奢华标杆（安缦）+ 经济标杆（锦江/汉庭）
> 核心规则：陶总五大反对 + 禁用词语表 | 标杆可验证，维度有出处

---

## 一、标杆分析蒸馏（Step 2）

### 1.1 标杆选择

| 标杆 | 定位 | 可验证来源 | 选择理由 |
|------|------|------------|----------|
| **万豪国际** | 全球最大酒店集团，覆盖经济到奢华 | 集团年报/品牌官网/STR数据 | 全品牌矩阵覆盖最完整，从 Fairfield（经济）到丽思卡尔顿（奢华） |
| **亚朵集团** | 国内中高端生活方式标杆 | 招股书/年报/品牌手册 | 以"睡眠+人文"差异化切入，是国内客房产品分类最细的中端品牌 |
| **安缦酒店** | 全球奢华独立标杆 | 官网/品牌白皮书/行业报告 | 奢华酒店的产品定义者，"空间+服务+隐私"三维模型行业公认 |
| **锦江之星/汉庭** | 中国经济型连锁标杆 | 锦江酒店年报/华住集团年报 | 经济型客房的标准化定义者，"干净+基本"的极简模型 |
| **希尔顿集团** | 国际商务型标杆 | 集团年报/品牌矩阵 | 商务客群分类最清晰，从 Hampton（中端）到华尔道夫（奢华） |

### 1.2 标杆拆解（找标杆 → 拆做法）

#### A. 万豪国际：全品牌产品矩阵

万豪的客房分类不单纯按价格分，而是按**品牌定位 × 服务承诺 × 忠诚度权益**三维分。

| 品牌层级 | 代表品牌 | 客房面积 | 核心产品特征 | 服务承诺 | 价格区间（一线） |
|----------|----------|----------|-------------|----------|-----------------|
| 经典奢华 | 丽思卡尔顿、瑞吉、JW万豪 | 45-80+㎡ | 全景景观+独立客厅+高端卫浴+管家 | 24h管家、定制化体验 | 2000-5000+ |
| 特色奢华 | W酒店、艾迪逊、豪华精选 | 40-70㎡ | 设计感+社交场景+夜店风/艺术风 | 潮流体验、社交空间 | 1500-4000 |
| 高级 | 万豪、喜来登、威斯汀 | 30-45㎡ | 商务+休闲平衡、天梦之床/白茶香氛 | 商务效率+ wellness | 800-1800 |
| 精选 | 万怡、福朋喜来登、雅乐轩 | 22-32㎡ | 标准商务/年轻客群、简约设计 | 基础商务服务+免费WiFi | 400-800 |
| 长住 |  Residence Inn、万豪行政公寓 | 35-60㎡ | 厨房+客厅+洗衣机，套房为主 | 长住设施、周清洁 | 600-1500 |
| 长住经济 | TownePlace Suites、万枫 | 20-30㎡ | 简易厨房+基础客厅，简洁实用 | 自助服务、有限前台 | 300-600 |

**万豪的关键维度提炼**：
- 品牌定位（奢华/高级/精选/长住）→ 不是产品功能，而是**客群身份匹配**
- 服务承诺层级（管家/定制化/标准/自助）→ 决定了**人房交互深度**
- 忠诚度权益（钛金/白金/金卡对应不同礼遇）→ 同一客房因身份不同体验不同

#### B. 亚朵集团：生活方式细分标杆

亚朵是国内第一个把客房产品按**生活场景**而非价格细分的品牌。

| 品牌 | 产品定位 | 核心差异 | 客房特征 | 价格区间 |
|------|----------|----------|----------|----------|
| 亚朵 | 标准中高端 | 睡眠+人文 | 普兰特床垫+萨和洗浴+属地摄影 | 350-600 |
| 亚朵S | 品质升级 | 设计+空间 | 更大面积+设计师合作+艺术装置 | 450-800 |
| 亚朵X | 轻中端 | 年轻+性价比 | 简洁设计+智能控制+社交大堂 | 250-450 |
| 亚朵轻居 | 轻旅居 | 年轻差旅 | 紧凑空间+基础功能+低价 | 200-350 |
| ZHotel | 电竞/社交 | 主题场景 | 电竞设备+社交空间+潮流设计 | 300-500 |

**亚朵的关键维度提炼**：
- 睡眠品质（床垫/枕头/床品分级）→ 亚朵的核心差异不是面积，是**睡眠体验**
- 人文氛围（属地摄影/书籍/香氛）→ 不是装修，是**情绪价值**
- 社交属性（大堂/共享空间）→ 客房不只是睡觉，是**场景延伸**

#### C. 安缦酒店：奢华产品定义者

安缦不自称"酒店"，自称"resort/ retreat"。其产品逻辑是**空间+在地+隐私**。

| 产品特征 | 具体做法 | 本质 |
|----------|----------|------|
| 空间尺度 | 每间房面积≥60㎡，套房≥100㎡，公共空间≤客房面积 | 空间即奢华，不是装修 |
| 在地融入 | 建筑设计由当地材料+当地工匠完成，每个酒店独一无二 | 不是标准化，是**不可复制** |
| 隐私隔离 | 低密度（每间酒店≤50间房），无大堂社交压力 | 隐私本身就是产品 |
| 服务无痕迹 | 无 bellboy 等仪式感，一切在客人开口前完成 | 服务不是表演，是**预判** |
| 无品牌标识 | 酒店外无 logo，房间内无品牌露出 | 品牌是信任，不是**炫耀** |

**安缦的关键维度提炼**：
- 空间稀缺性（低密度+大面积）→ 不是大就好，是**稀缺**
- 在地独特性（不可复制）→ 不是设计好，是**唯一**
- 服务预判（无痕迹）→ 不是服务多，是**恰好**

#### D. 锦江/汉庭：经济型标准化标杆

| 品牌 | 产品定位 | 核心承诺 | 客房标准 | 价格区间 |
|------|----------|----------|----------|----------|
| 锦江之星 | 标准经济 | 干净+安全 | 15-20㎡，标准床+基础卫浴 | 150-250 |
| 汉庭（2.7/3.0） | 经济升级 | 干净+智能 | 18-24㎡，智能控制+品牌床品 | 180-350 |
| 海友 | 超经济 | 睡觉即可 | 10-15㎡，公共卫浴可选 | 80-150 |

**经济型标杆提炼**：
- 底线标准（干净/安全）→ 不是产品好，是**底线不出事**
- 标准化可复制（每家店一模一样）→ 不是惊喜，是**确定**
- 成本极限（每平米造价/运营成本严格控制）→ 价格是产品本身的一部分

### 1.3 差距评估与借鉴（评差距 → 定借鉴）

| 公司现状 | 标杆做法 | 差距 | 可借鉴点 |
|----------|----------|------|----------|
| 仅有价格分层（经济/中/高） | 万豪：品牌定位×服务承诺×忠诚度三维 | 维度单一，无法解释同一价格不同体验 | 增加**服务承诺层级**和**客群身份匹配**维度 |
| 无生活方式细分 | 亚朵：睡眠+人文+社交场景 | 产品同质化，只能靠价格竞争 | 增加**睡眠品质**和**情绪价值**维度 |
| 无奢华定义 | 安缦：空间稀缺+在地唯一+服务预判 | 对高端产品的定义停留在"面积大/装修贵" | 增加**空间稀缺性**和**服务预判**维度 |
| 无标准化底线 | 锦江/汉庭：干净+安全+可复制 | 基础产品定义模糊，质量控制不稳定 | 增加**底线标准**和**标准化程度**维度 |

## 二、产品分析模型（5维度，标杆蒸馏版）

基于标杆拆解，提炼5个本质维度。每个维度有标杆出处、客观数据、下一步动作。

### 维度1：空间硬件（源自万豪+安缦）
**核心问题**：这间房在物理空间和硬件上提供什么？

| 子项 | 客观描述 | 标杆出处 | 数据类型 | 下一步动作 |
|------|----------|----------|----------|------------|
| 面积 | 15-20㎡ / 20-28㎡ / 28-35㎡ / 35-50㎡ / 50㎡+ | 万豪： Fairfield 20㎡ vs 丽思卡尔顿 60+㎡；安缦：≥60㎡ | 数值区间 | 根据旅客人数和行李量判断空间需求 |
| 床型 | 单人床(1.0m) / 标准大床(1.5m) / 加大床(1.8m) / 特大床(2.0m) / 双床(1.2m×2) / 家庭套房(多床) | 万豪全品牌标准床型矩阵；亚朵普兰特床垫分级 | 枚举 | 根据出行人数和关系判断床型需求 |
| 景观 | 无窗 / 内景(走廊/天井) / 城景 / 海景 / 湖景 / 花园 / 地标景观 | 安缦：景观是核心产品；万豪：高级品牌标配景观 | 枚举 | 根据出行目的判断景观权重（休闲>商务） |
| 卫浴 | 标准淋浴 / 淋浴+浴缸 / 独立干湿分离 / 双台盆+高端卫浴 / 独立桑拿/SPA | 万豪：瑞吉双台盆+高端卫浴；安缦：独立浴缸是标配 | 枚举 | 根据停留时长和舒适度要求判断 |
| 睡眠品质 | 经济床品 / 标准品牌床品 / 中高端品牌（普兰特/金可儿） / 奢华品牌（席梦思黑标/海丝腾） | 亚朵：普兰特床垫是核心卖点；万豪：天梦之床是威斯汀标志 | 枚举 | 根据旅客对睡眠敏感度判断（商务客高敏感） |
| 特殊设施 | 阳台 / 露台 / 厨房 / 客厅分区 / 办公区 / 迷你吧 | 万豪 Residence Inn：厨房是长住标配；安缦：阳台/庭院是标配 | 布尔/枚举 | 根据长住/家庭/商务需求判断 |

**标杆支撑**：万豪面积矩阵+安缦空间稀缺性+亚朵睡眠品质

### 维度2：服务层级（源自万豪+安缦）
**核心问题**：住这间房能享受什么服务和权益？

| 子项 | 客观描述 | 标杆出处 | 数据类型 | 下一步动作 |
|------|----------|----------|----------|------------|
| 服务响应 | 自助服务 / 前台标准服务 / 优先入住退房 / 24h管家 / 私人管家 | 安缦：无痕迹服务；万豪：白金/钛金优先通道 | 枚举 | 根据旅客时间紧迫度判断 |
| 专属空间 | 无 / 行政酒廊 / 贵宾休息区 / 专属餐厅 / 私人会所 | 万豪：行政酒廊是高级品牌标配；安缦：无公共空间压力 | 枚举 | 根据商务/休闲目的判断 |
| 早餐等级 | 无早餐 / 简餐(面包咖啡) / 自助早餐 / 定制早餐 / 客房送餐 / 全餐服务 | 万豪：丽思卡尔顿定制早餐；亚朵：属地早餐 | 枚举 | 根据出行时段和习惯判断 |
| 礼遇权益 | 无 / 延迟退房 / 免费升房 / 欢迎礼品 / 接送机 / 熨衣服务 / SPA券 | 万豪旅享家：忠诚度权益体系；安缦：全包式礼遇 | 多选布尔 | 根据消费水平判断权重 |
| 特殊服务 | 无 / 儿童看护 / 宠物接待 / 无障碍服务 / 商务秘书 / 医疗支持 | 万豪：商务秘书是高级品牌标配；安缦：预判式服务 | 多选布尔 | 根据特殊需求标签直接匹配 |
| 服务预判 | 无 / 基础预判（提前开夜床） / 中级预判（根据入住记录准备） / 高级预判（开口前完成） | 安缦：服务预判是核心差异；万豪：高端客户档案管理 | 枚举 | 根据旅客频次（首住/复住/常客）判断 |

**标杆支撑**：万豪旅享家权益体系+安缦无痕迹服务+亚朵属地服务

### 维度3：价格定位（源自万豪+锦江）
**核心问题**：这间房在什么价格带？性价比如何？

| 子项 | 客观描述 | 标杆出处 | 数据类型 | 下一步动作 |
|------|----------|----------|----------|------------|
| 价格区间 | 按城市等级分档（一线城市/新一线/二线/旅游城市）给出具体区间 | 万豪：全球动态定价系统；锦江：经济型底线价格 | 数值区间 | 与旅客预算区间直接比对 |
| 性价比评分 | 综合评分/评价数/价格的三维计算值 | 华住：汉庭3.0性价比模型；亚朵：用户评分权重高 | 0-100分 | 在同级产品中做横向比较 |
| 动态定价特征 | 平日价 / 周末价 / 旺季价 / 活动价 / 会员价 | 万豪：全球收益管理系统；国内：会员价是核心差异 | 价格矩阵 | 根据入住日期匹配实时价格 |
| 附加费用透明度 | 明确列出服务费、税费、早餐费、停车费等是否含在房价内 | 锦江：经济型全透明定价；安缦：一价全包模式 | 布尔/枚举 | 对价格敏感旅客主动提示 |
| 成本结构 | 基础成本型（经济型极限成本） / 体验溢价型（中高端） / 身份溢价型（奢华） | 万豪：不同层级毛利率差异巨大；安缦：身份溢价>体验成本 | 枚举 | 根据旅客价格敏感度判断（敏感度越高越推荐成本透明型） |

**标杆支撑**：万豪收益管理+锦江成本极限+安缦一价全包

### 维度4：品牌档次（源自万豪+亚朵）
**核心问题**：这个酒店品牌在什么层级？调性是什么？

| 子项 | 客观描述 | 标杆出处 | 数据类型 | 下一步动作 |
|------|----------|----------|----------|------------|
| 星级定位 | 经济型 / 舒适型 / 高端型 / 奢华型 | 万豪：经典奢华→精选→长住经济五级；亚朵：轻居→X→亚朵→S四级 | 枚举 | 与旅客消费层次直接匹配 |
| 品牌调性 | 商务干练 / 休闲度假 / 设计艺术 / 经典传统 / 精品小众 / 生活方式 | 亚朵：生活方式是核心差异；W酒店：潮流设计；安缦：在地传统 | 枚举 | 与旅客品味倾向匹配 |
| 品牌认知度 | 国际连锁 / 国内连锁 / 区域知名 / 本地精品 / 独立奢华 | 万豪：国际连锁认知度最高；安缦：独立奢华认知度精准 | 枚举 | 对品牌有明确要求的旅客直接匹配 |
| 客群画像标签 | 商旅常客 / 家庭出游 / 情侣度假 / 高端休闲 / 背包客 / 生活方式追求者 | 亚朵：生活方式追求者；万豪：商旅常客是基本盘；安缦：高端休闲+隐私追求者 | 多选 | 与旅客画像做相似度计算 |
| 标准化程度 | 全球统一复制（100%一致） / 区域标准（80%一致） / 品牌框架（50%一致） / 独一无二（每家不同） | 汉庭：全球100%一致；万豪：品牌框架内一致；安缦：每家独一无二 | 枚举 | 根据旅客对确定性的需求判断（商务客要一致，休闲客要惊喜） |

**标杆支撑**：万豪品牌矩阵+亚朵生活方式+安缦独一无二

### 维度5：应用适配（源自全标杆综合）
**核心问题**：这间房最适合什么类型的旅客和出行情况？

| 子项 | 客观描述 | 标杆出处 | 数据类型 | 下一步动作 |
|------|----------|----------|----------|------------|
| 主要客群 | 单人商旅 / 双人出行 / 家庭(带儿童) / 团队 / 长住客 / 隐私追求者 | 万豪：长住品牌单独设线；安缦：隐私追求者专属 | 枚举 | 与旅客出行人数直接匹配 |
| 适配出行目的 | 商务会议 / 标准出差 / 休闲度假 / 家庭出游 / 蜜月庆祝 / 中转停留 / 医疗陪护 / 长住生活 | 万豪：长住品牌对应长住生活；安缦：度假是核心；亚朵：商旅是核心 | 多选 | 与旅客出行目的直接比对 |
| 时长适配 | 过夜(1晚) / 短期(2-3晚) / 中期(4-7晚) / 长期(7晚+) | 万豪 Residence Inn：7晚+是核心客群；安缦：2-3晚是最佳体验时长 | 枚举 | 根据预订时长判断（长住需厨房/客厅） |
| 位置便利性 | 机场周边 / 商务区 / 景区周边 / 交通枢纽 / 居民区 / 隐世度假 | 亚朵：商务区核心；安缦：隐世度假是核心差异；万豪：机场/商务区全覆盖 | 枚举 | 根据出行目的判断位置权重 |
| 安静/热闹倾向 | 安静(高层/庭院) / 热闹(低层/近设施) / 社交型(近大堂/酒吧) / 无所谓 | 安缦：安静是核心；W酒店：社交型是核心；万豪：按品牌分层 | 枚举 | 根据旅客睡眠质量和出行目的判断 |
| 情绪价值 | 无 / 基础舒适 / 放松治愈 / 惊喜体验 / 身份认同 / 精神共鸣 | 亚朵：属地摄影+书籍提供情绪价值；安缦：精神共鸣是核心；W酒店：惊喜体验 | 枚举 | 根据旅客出行目的（休闲/纪念/疗愈）判断 |

**标杆支撑**：万豪全品牌覆盖+亚朵情绪价值+安缦精神共鸣

## 三、标杆产品分类体系（5类，有标杆出处）

产品分类基于标杆做法提炼，不是凭空拍脑袋。控制在5类。

### A. 基础客房（入门级）
**本质定位**：满足底线住宿需求，标准化可复制，成本极限。  
**标杆出处**：锦江之星（干净+安全）、汉庭2.7（干净+智能）、万豪 Fairfield（基础+标准）。

| **产品名称** | 基础客房 / 经济大床房 / 标准双床房 |
| **面积** | 15-22㎡ |
| **床型** | 标准大床(1.5m) / 标准双床(1.2m×2) |
| **睡眠品质** | 经济型床品（基础弹簧床垫） |
| **景观** | 无窗或内景(走廊/天井) |
| **卫浴** | 标准淋浴，无浴缸，紧凑布局 |

| **早餐** | 无或简餐(面包+咖啡) |
| **价格区间** | 一线城市150-350元 / 新一线100-280元 / 二线80-220元 |
| **品牌档次** | 经济型连锁（汉庭/锦江/7天/如家） |
| **标准化程度** | 全球100%一致复制 |

| **睡眠品质** | 中高端品牌床品（普兰特/金可儿级别） |
| **景观** | 标准城景或普通窗景 |

## 五、自动匹配动作模型（标杆增强版）

### 动作定义

| 字段 | 定义 |
|------|------|
| **动作名称** | 客房产品自动匹配（标杆增强版） |
| **触发条件** | 旅客输入画像（或系统获取画像）包含：消费水平、出行目的、人数、天数、特殊需求中的至少3项 |
| **服务对象** | 预订系统、前台人员、旅客本人 |
| **执行角色** | AI匹配引擎（产品推荐助理） |
| **验收角色** | 前台人员（最终确认）、旅客（选择下单） |

### 执行步骤（含标杆校验）

| 步骤 | 动作 | 输入 | 输出 | 标杆校验 | 异常处理 |
|------|------|------|------|----------|----------|
| 1 | 提取旅客特征 | 旅客画像原始数据 | 结构化特征向量（5维度匹配值） | 参照万豪客群分类矩阵 | 数据缺失>2项 → 请求补充关键信息（消费水平+出行目的） |
| 2 | 初筛产品池 | 特征向量 + 全量产品库 | 符合硬性条件的产品子集（价格区间+人数适配） | 参照亚朵价格-品质对应关系 | 无匹配产品 → 扩大价格区间20%或降低人数要求 |
| 3 | 多维评分 | 产品子集 + 特征向量 | 每款产品匹配度评分（0-100）+ 维度得分明细 | 参照安缦"预判"理念，增加常客权重 | 评分差距<5分 → 增加权重维度（如景观/服务预判） |
| 4 | 标杆对标 | 评分结果 | 标杆匹配说明（"此推荐对标亚朵/万豪XX标准"） | 每个推荐附带标杆出处 | 无标杆对应 → 标记为"创新产品，建议谨慎" |
| 5 | 生成推荐排序 | 评分+标杆对标 | Top 3推荐列表 + 每款匹配理由 + 标杆出处 | 交叉验证合理性 | 评分均<60分 → 输出"无理想匹配"+最接近选项 |
| 6 | 输出推荐 | 推荐列表 | 带匹配理由+标杆出处+风险提示的产品卡片 | 最终自检 | 目标产品无房 → 推荐同级替代产品（参照万豪品牌升级逻辑） |

- 消费水平：预算800元/晚

- 特殊需求：安静、需要办公空间、睡眠敏感

**匹配过程**：
1. 特征提取 → 单人商务、预算800、2晚、安静+办公+睡眠敏感
2. 初筛 → 价格区间350-1200的产品：B/C/D
3. 多维评分（标杆增强）：
   - B(标准)：价格匹配(90)、商务适配(60)、安静(50)、办公(30)、睡眠品质(70) → 总分60
   - C(商务)：价格匹配(85)、商务适配(95)、安静(80)、办公(90)、睡眠品质(85) → 总分87
   - D(豪华)：价格匹配(60)、商务适配(75)、安静(70)、办公(70)、睡眠品质(90) → 总分73
4. 标杆对标：C对标万豪/喜来登商务标准，B对标亚朵/万怡
5. 推荐排序：C(87) > D(73) > B(60)
6. 输出：Top 1=商务客房，匹配理由=商务适配度最高+办公空间+安静朝向+睡眠助眠配置，标杆出处=万豪/喜来登商务标准
