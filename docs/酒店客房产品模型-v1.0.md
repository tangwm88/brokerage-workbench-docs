# 酒店客房产品模型 v1.0

> 基于模型蒸馏智能体五步法输出 | 适用：AI自动匹配旅客与酒店客房产品
> 核心规则：陶总五大反对 + 禁用词语表 | 人定维度，AI执行匹配

---

## 一、模型定义

### 1.1 目的
让AI系统根据旅客分层画像、消费水平、出行目的等输入，自动匹配并推荐最合适的酒店客房产品，给出可解释的推荐理由。

### 1.2 服务对象
- **主要角色**：预订系统、前台人员、线上推荐引擎
- **受益角色**：旅客（获得精准推荐）、酒店（提升转化率）

### 1.3 核心输入
- 旅客分层画像（年龄层、职业类型、消费层次）
- 消费水平（预算区间、价格敏感度）
- 出行目的（商务/休闲/家庭/中转/特殊庆祝）
- 出行人数与时长（单人/双人/家庭/长住）
- 特殊需求（安静、景观、宠物、无障碍等）

### 1.4 核心输出
- 推荐产品排序（Top 3，按匹配度降序）
- 匹配理由（每款产品为何适合该旅客）
- 风险提示（如价格超预算、无可用房等）

## 二、产品分析模型（5维度）

每个维度讲人话、有客观数据、有下一步动作。维度数量硬性控制在5个，不堆砌。

### 维度1：空间硬件
**核心问题**：这间房在物理空间和硬件上提供什么？

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 面积 | 15-20㎡ / 20-28㎡ / 28-35㎡ / 35-50㎡ / 50㎡+ | 数值区间 | 根据旅客人数和行李量判断空间需求 |
| 床型 | 单人床(1.0m) / 标准大床(1.5m) / 加大床(1.8m) / 特大床(2.0m) / 双床(1.2m×2) / 家庭套房(多床) | 枚举 | 根据出行人数和关系判断床型需求 |
| 景观 | 无窗 / 内景(走廊/天井) / 城景 / 海景 / 湖景 / 花园 / 地标景观 | 枚举 | 根据出行目的判断景观权重（休闲>商务） |
| 卫浴 | 标准淋浴 / 淋浴+浴缸 / 独立干湿分离 / 双台盆+高端卫浴 / 独立桑拿/SPA | 枚举 | 根据停留时长和舒适度要求判断 |
| 特殊设施 | 阳台 / 露台 / 厨房 / 客厅分区 / 办公区 / 迷你吧 | 布尔/枚举 | 根据长住/家庭/商务需求判断 |

**禁用词检查**：无。

### 维度2：服务层级
**核心问题**：住这间房能享受什么服务和权益？

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 服务响应 | 前台标准服务 / 优先入住退房 / 24h管家 / 私人管家 | 枚举 | 根据旅客时间紧迫度判断 |
| 专属空间 | 无 / 行政酒廊 / 贵宾休息区 / 专属餐厅 | 枚举 | 根据商务/休闲目的判断 |
| 早餐等级 | 无早餐 / 简餐(面包咖啡) / 自助早餐 / 定制早餐 / 客房送餐 / 全餐服务 | 枚举 | 根据出行时段和习惯判断 |
| 礼遇权益 | 延迟退房 / 免费升房 / 欢迎礼品 / 接送机 / 熨衣服务 / SPA券 | 多选布尔 | 根据消费水平判断权重 |
| 特殊服务 | 无 / 儿童看护 / 宠物接待 / 无障碍服务 / 商务秘书 | 多选布尔 | 根据特殊需求标签直接匹配 |

**禁用词检查**：无。

### 维度3：价格定位
**核心问题**：这间房在什么价格带？性价比如何？

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 价格区间 | 按城市等级分档（一线城市/新一线/二线/旅游城市）给出具体区间 | 数值区间 | 与旅客预算区间直接比对 |
| 性价比评分 | 综合评分/评价数/价格的三维计算值 | 0-100分 | 在同级产品中做横向比较 |
| 动态定价特征 | 平日价 / 周末价 / 旺季价 / 活动价 / 会员价 | 价格矩阵 | 根据入住日期匹配实时价格 |
| 附加费用透明度 | 明确列出服务费、税费、早餐费、停车费等是否含在房价内 | 布尔/枚举 | 对价格敏感旅客主动提示 |

**禁用词检查**：无。

### 维度4：品牌档次
**核心问题**：这个酒店品牌在什么层级？调性是什么？

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 星级定位 | 经济型 / 舒适型 / 高端型 / 奢华型 | 枚举 | 与旅客消费层次直接匹配 |
| 品牌调性 | 商务干练 / 休闲度假 / 设计艺术 / 经典传统 / 精品小众 | 枚举 | 与旅客品味倾向匹配 |
| 品牌认知度 | 国际连锁 / 国内连锁 / 区域知名 / 本地精品 | 枚举 | 对品牌有明确要求的旅客直接匹配 |
| 客群画像标签 | 商旅常客 / 家庭出游 / 情侣度假 / 高端休闲 / 背包客 | 多选 | 与旅客画像做相似度计算 |

**禁用词检查**：无。

### 维度5：应用适配
**核心问题**：这间房最适合什么类型的旅客和出行情况？

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 主要客群 | 单人商旅 / 双人出行 / 家庭(带儿童) / 团队 / 长住客 | 枚举 | 与旅客出行人数直接匹配 |
| 适配出行目的 | 商务会议 / 标准出差 / 休闲度假 / 家庭出游 / 蜜月庆祝 / 中转停留 / 医疗陪护 | 多选 | 与旅客出行目的直接比对 |
| 时长适配 | 过夜(1晚) / 短期(2-3晚) / 中期(4-7晚) / 长期(7晚+) | 枚举 | 根据预订时长判断（长住需厨房/客厅） |
| 位置便利性 | 机场周边 / 商务区 / 景区周边 / 交通枢纽 / 居民区 | 枚举 | 根据出行目的判断位置权重 |
| 安静/热闹倾向 | 安静(高层/庭院) / 热闹(低层/近设施) / 无所谓 | 枚举 | 根据旅客睡眠质量和出行目的判断 |

**禁用词检查**：无。注意："场景"已替换为"出行目的"和"应用情况"。

## 三、产品分类体系（5类）

产品分类不是按酒店品牌分，而是按客房产品的本质差异分。控制在5类，不堆砌。

### A. 经济客房（入门级）
**本质定位**：满足基本住宿需求，预算优先。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 经济客房 / 标准大床房 / 基础双床房 |
| **面积** | 15-20㎡ |
| **床型** | 标准大床(1.5m) / 标准双床(1.2m×2) |
| **景观** | 无窗或内景(走廊/天井) |
| **卫浴** | 标准淋浴，无浴缸 |
| **服务** | 前台标准服务，无专属权益 |
| **早餐** | 无或简餐(面包+咖啡) |
| **价格区间** | 一线城市150-300元 / 新一线100-250元 / 二线80-200元 |
| **品牌档次** | 经济型连锁 |
| **适配客群** | 预算敏感旅客、中转停留、学生/背包客、短期过夜 |
| **出行目的** | 中转停留、考试/面试过夜、最低预算出行 |
| **核心卖点** | 价格低、干净、基本设施齐全 |
| **主要短板** | 空间小、无景观、服务简单、无早餐 |

### B. 舒适客房（标准级）
**本质定位**：满足常规出行需求，性价比平衡。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 舒适客房 / 高级大床房 / 豪华双床房 |
| **面积** | 20-28㎡ |
| **床型** | 加大床(1.8m) / 标准双床(1.2m×2) |
| **景观** | 标准城景或普通窗景 |
| **卫浴** | 淋浴+浴缸可选，标准配置 |
| **服务** | 标准服务，延迟退房至14:00 |
| **早餐** | 自助早餐 |
| **价格区间** | 一线城市300-500元 / 新一线250-450元 / 二线200-350元 |
| **品牌档次** | 舒适型连锁 / 中端品牌 |
| **适配客群** | 常规商旅、家庭休闲、标准出游、情侣出行 |
| **出行目的** | 标准出差、周末休闲、家庭短途游、常规度假 |
| **核心卖点** | 空间适中、有早餐、服务标准、品牌可信 |
| **主要短板** | 无专属服务、无特殊景观、卫浴标准 |

### C. 商务客房（专业级）
**本质定位**：满足商务出行效率和专业需求。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 商务客房 / 行政大床房 / 商务双床房 |
| **面积** | 25-35㎡ |
| **床型** | 加大床(1.8m) / 双床(1.2m×2) |
| **景观** | 优选城景或安静朝向（远离电梯/低楼层） |
| **卫浴** | 独立干湿分离，标准淋浴+浴缸 |
| **服务** | 快速入住/退房、行政酒廊、24h服务响应、商务秘书 |
| **早餐** | 自助+定制（可打包） |
| **价格区间** | 一线城市500-800元 / 新一线400-650元 / 二线350-550元 |
| **品牌档次** | 中高端商务 |
| **适配客群** | 商务出差、会议接待、高频商旅、企业协议客户 |
| **出行目的** | 商务会议、标准出差、项目驻场、客户接待 |
| **核心卖点** | 效率优先、安静、办公便利、行政酒廊、商务服务 |
| **主要短板** | 价格偏高、休闲属性弱、家庭设施少 |

### D. 豪华客房（高端级）
**本质定位**：满足品质追求和度假体验，享受优先。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 豪华客房 / 景观大床房 / 行政豪华房 |
| **面积** | 35-50㎡ |
| **床型** | 特大床(2.0m) / 双床(1.35m×2) |
| **景观** | 优选景观（海景/湖景/地标/花园） |
| **卫浴** | 高端卫浴品牌、独立浴缸+独立淋浴、双台盆 |
| **服务** | 专属管家、优先通道、礼宾服务、优先升房 |
| **早餐** | 定制早餐或客房送餐 |
| **价格区间** | 一线城市800-1500元 / 新一线650-1200元 / 二线500-900元 |
| **品牌档次** | 高端/奢华 |
| **适配客群** | 高端商务、度假休闲、纪念日情侣、品质追求者 |
| **出行目的** | 高端商务、度假休闲、蜜月旅行、纪念日庆祝、品质出游 |
| **核心卖点** | 景观佳、空间大、卫浴高端、服务专属、品牌溢价 |
| **主要短板** | 价格高、性价比低（对预算敏感者）、商务效率未必最优 |

### E. 套房产品（尊享级）
**本质定位**：满足空间多样化和尊享体验，多功能力优先。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 行政套房 / 家庭套房 / 总统套房 / 复式套房 |
| **面积** | 50-100+㎡ |
| **空间** | 客厅+卧室分区，部分带厨房/餐厅，多卧室可选 |
| **床型** | 特大床+沙发床 / 多卧室配置 |
| **景观** | 最佳景观位（顶层/角落/全景） |
| **卫浴** | 双台盆+独立浴缸+独立淋浴，部分带桑拿/SPA |
| **服务** | 私人管家、全套行政礼遇、接送机、熨衣/SPA服务 |
| **早餐** | 全餐服务（客房用餐/餐厅包厢） |
| **价格区间** | 一线城市1500-5000+元 / 新一线1200-4000+元 / 二线1000-3000+元 |
| **品牌档次** | 奢华品牌 |
| **适配客群** | 家庭长住、高端商务、VIP接待、特殊庆祝、名人/高管 |
| **出行目的** | 家庭长住(7晚+)、高端商务接待、婚礼/蜜月套房、VIP接待、特殊庆祝 |
| **核心卖点** | 空间多样、私密性强、全服务覆盖、身份象征、长住便利 |
| **主要短板** | 价格高、利用率低（单人住浪费）、预订门槛高 |

## 五、自动匹配动作模型

**事件驱动**：旅客输入需求 → 触发匹配 → 输出推荐。
不是线性流程，是可调用原子库。

### 动作定义

| 字段 | 定义 |
|------|------|
| **动作名称** | 客房产品自动匹配 |
| **触发条件** | 旅客输入画像（或系统获取画像）包含：消费水平、出行目的、人数、天数、特殊需求中的至少3项 |
| **服务对象** | 预订系统、前台人员、旅客本人 |
| **执行角色** | AI匹配引擎（产品推荐助理） |
| **验收角色** | 前台人员（最终确认）、旅客（选择下单） |

### 执行步骤

| 步骤 | 动作 | 输入 | 输出 | 异常处理 |
|------|------|------|------|----------|
| 1 | 提取旅客特征 | 旅客画像原始数据 | 结构化特征向量（5维度匹配值） | 数据缺失>2项 → 请求补充关键信息（消费水平+出行目的） |
| 2 | 初筛产品池 | 特征向量 + 全量产品库 | 符合硬性条件的产品子集（价格区间+人数适配） | 无匹配产品 → 扩大价格区间20%或降低人数要求 |
| 3 | 多维评分 | 产品子集 + 特征向量 | 每款产品匹配度评分（0-100）+ 维度得分明细 | 评分差距<5分 → 增加权重维度（如景观/服务） |
| 4 | 生成推荐排序 | 评分结果 | Top 3推荐列表 + 每款匹配理由 | 评分均<60分 → 输出"无理想匹配"+最接近选项 |
| 5 | 输出推荐 | 推荐列表 | 带匹配理由的产品卡片 + 价格 + 可用性 + 风险提示 | 目标产品无房 → 推荐同级替代产品 |

### 匹配规则（核心规律）

| 旅客特征 | 优先匹配产品 | 匹配理由 |
|----------|-------------|----------|
| 预算<300元/晚 + 单人 + 1-2晚 | 经济客房(A) | 满足基本住宿，价格最低 |
| 预算300-600元/晚 + 双人 + 标准出差 | 舒适客房(B) | 性价比最高，有早餐，空间适中 |
| 预算500-1000元/晚 + 商务 + 时间紧迫 | 商务客房(C) | 效率优先，行政酒廊，快速服务 |
| 预算800+元/晚 + 休闲/纪念日 + 景观要求 | 豪华客房(D) | 体验优先，景观佳，服务专属 |
| 家庭4人 + 长住5晚+ + 预算1500+ | 套房产品(E) | 空间分区，厨房便利，全服务 |
| 单人 + 中转 + 预算<200 | 经济客房(A) | 过夜即可，不浪费 |
| 情侣 + 蜜月 + 预算充足 | 豪华客房(D)或套房(E) | 景观+服务+私密性 |
| 高频商旅 + 协议价 + 效率要求 | 商务客房(C) | 企业协议，积分累计，效率最优 |
| 家庭出游 + 儿童 + 安全/设施 | 舒适客房(B)或套房(E) | 空间够，早餐方便，安全 |
