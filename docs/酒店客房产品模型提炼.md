# 酒店客房产品模型提炼

> 从v2.2模型方案中提炼核心结构，直接可用

---

## 一、酒店客房产品主要维度（7维度）

| 维度 | 核心问题 | 关键子项 |
|------|----------|----------|
| **硬件设施** | 这间房在物理空间和硬件上提供什么？ | 面积、床型、睡眠品质、景观、卫浴、特殊设施 |
| **空间位置** | 这间房在什么位置？周边是什么环境？ | 城市区位、交通便利性、周边配套、客房朝向、楼层位置、噪声环境 |
| **服务范围** | 住这间房能享受什么服务和权益？ | 服务响应、专属空间、早餐等级、礼遇权益、特殊服务、服务预判 |
| **价格定位** | 这间房在什么价格带？性价比如何？ | 价格区间、性价比评分、动态定价特征、附加费用透明度、成本结构 |
| **风格特征** | 这个房间是什么风格？给客户什么感受？ | 风格类型（温馨型/商务型/度假型/简约型/豪华型/艺术型/在地型）、情绪感受（放松/兴奋/平静/愉悦/身份感）、设计元素（现代/古典/自然/科技/民族）、记忆点（香氛/音乐/色彩/灯光/艺术品） |
| **客群适配** | 这个产品最适合什么类型的旅客和出行情况？ | 主要客群、出行目的、时长适配、安静倾向 |
| **运营约束** | 什么时间能入住？有什么门槛？ | 入住/退房时间、预订要求、房态、取消政策、支付方式、押金要求 |

## 二、酒店客房产品类型（5类）

| 产品类型 | 本质定位 | 面积 | 价格（一线） | 标杆出处 |
|----------|----------|------|-------------|----------|
| **基础客房** | 满足底线住宿，标准化可复制 | 15-22㎡ | 150-350 | 汉庭/锦江/万枫 |
| **舒适客房** | 睡眠品质有保障，性价比平衡 | 22-30㎡ | 350-600 | 亚朵/万怡/全季 |
| **商务客房** | 效率优先，服务预判+行政支持 | 28-40㎡ | 600-1200 | 万豪/希尔顿/亚朵S |
| **豪华客房** | 景观+体验+情绪沉浸 | 35-55㎡ | 1200-2500 | 威斯汀/W/艾美 |
| **套房产品** | 空间+隐私+在地唯一 | 50-150+㎡ | 2500-8000+ | 安缦/丽思卡尔顿/瑞吉 |

## 四、酒店外住宿产品（周边替代）

| 产品类型 | 核心方式 | 距离 | 价格 | 核心场景 |
|----------|----------|------|------|----------|
| **民宿/公寓** | Airbnb/途家/当地民宿，独立空间 | 同区域 | 200-800 | 长住、家庭、想自己做饭 |
| **青年旅舍** | 多人间/床位，公共空间 | 同区域 | 50-150 | 背包客、预算极低、社交 |
| **服务式公寓** | 品牌公寓，含厨房/洗衣，月租 | 同区域 | 300-1000/天 | 长住7天+、商务派驻、家庭 |
| **短租别墅** | 整套别墅，私人空间，多人 | 郊区/景区 | 1000-5000+ | 家庭聚会、团建、派对 |
| **胶囊旅馆** | 胶囊床位，极简，仅限睡觉 | 交通枢纽 | 80-200 | 单人过夜、中转、极简需求 |

### 酒店外子类示例

| 产品类型 | 子类示例 |
|----------|----------|
| **民宿/公寓** | 城市民宿（整套公寓）、景区民宿（古镇/海边）、亲子民宿（儿童设施） |
| **青年旅舍** | 国际青旅（多国籍）、精品青旅（设计感）、主题青旅（电竞/电影） |
| **服务式公寓** | 品牌服务公寓（如雅诗阁）、当地服务公寓（如本地长租公寓）、企业协议公寓 |
| **短租别墅** | 度假别墅（海景/山景）、轰趴别墅（娱乐设施）、温泉别墅 |
| **胶囊旅馆** | 机场胶囊（中转）、城市胶囊（极简）、主题胶囊（太空舱/日式） |

## 五、旅客分析-客房-周边完整联动

| 旅客分析 | 推荐客房 | 酒店外替代（触发时） |
|----------|----------|---------------------|
| **预算<200 + 单人 + 1晚** | 基础客房 | 胶囊旅馆 / 青年旅舍 |
| **预算200-400 + 双人 + 标准出差** | 舒适客房 | 民宿/公寓（性价比更高） |
| **预算600-1000 + 商务 + 效率** | 商务客房 | 服务式公寓（长住更划算） |
| **预算1200+ + 休闲/纪念日 + 景观** | 豪华客房 | 短租别墅（私密性更强） |
| **家庭4人 + 长住7晚+** | 套房产品 | 短租别墅 / 服务式公寓（有厨房更实用） |
| **预算敏感 + 长住30天+** | 舒适客房（长住折扣） | 服务式公寓（月租价） |
| **多人团建/聚会** | 套房产品 | 短租别墅（空间更大、更自由） |
| **想体验当地/管家服务** | 豪华客房 | 高端民宿（在地体验+主人文化） |
