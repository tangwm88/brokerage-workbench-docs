# 酒店客房产品模型 v2.2 — 自然语言输出版（方案A增强）

> 基于五步法完整执行：Step 1 业务目标 → Step 2 标杆分析 → Step 3 数据关联 → Step 4 模型定义 → Step 5 交叉验证
> 核心规则：陶总五大反对 + 禁用词语表 | 人定维度，AI执行匹配 | 标杆可验证，产品可创新

---

## 一、模型定义

### 1.1 目的
基于万豪、亚朵、安缦、希尔顿、锦江五家标杆酒店的客房产品分析，提炼最大公约数，形成创新的酒店客房产品分类体系。让AI系统根据客户分层分析、消费水平、出行目的等输入，自动匹配并推荐最合适的创新客房产品，给出可解释的推荐理由。

### 1.2 服务对象（角色体系）

| 角色 | 定义 | 核心诉求 | 与产品的关系 |
|------|------|----------|-------------|
| **酒店客户** | 入住酒店的旅客 | 获得与自身需求精准匹配的住宿体验 | 产品的最终体验者和评判者 |
| **酒店前台员工** | 执行入住、咨询、预订、推荐的一线员工 | 快速准确地向客户推荐合适的客房产品 | 产品的推荐执行者，需要清晰的产品卡片和匹配理由 |
| **客房服务员工** | 执行客房清洁、维护、服务的一线员工 | 按照产品标准提供服务，识别产品差异 | 产品的服务交付者，需要明确的服务标准和预判要求 |
| **酒店经营者** | 负责定价、产品定义、品质控制的管理者 | 产品体系清晰可管理，定价有依据，迭代有数据 | 产品的定义者和迭代决策者 |

> **角色校验**：四个角色边界清晰，无重叠。酒店客户是核心用户，前台和客房员工是服务交付方，经营者是管理组织方。符合"角色跟着目的走"原则。

### 1.3 核心输入
- 酒店客户分层分析（年龄层、职业类型、消费层次）
- 消费水平（预算区间、价格敏感度）
- 出行目的（商务/休闲/家庭/中转/特殊庆祝/长住）
- 出行人数与时长（单人/双人/家庭/团队/长住）
- 特殊需求（安静、景观、宠物、无障碍、睡眠敏感等）

### 1.4 核心输出
- 推荐产品排序（Top 3，按匹配度降序）
- 匹配理由（每款产品为何适合该客户）
- 服务预判建议（针对前台/客房员工的执行提示）
- 风险提示（如价格超预算、无可用房等）

## 二、标杆分析蒸馏（Step 2）

### 2.1 标杆选择

| 标杆 | 定位 | 可验证来源 | 选择理由 |
|------|------|------------|----------|
| **万豪国际** | 全球最大酒店集团，30+品牌覆盖全层级 | 集团年报/品牌官网/STR数据 | 全品牌矩阵覆盖最完整，是客房产品分类的"行业字典" |
| **亚朵集团** | 国内中高端生活方式标杆 | 招股书/年报/品牌手册 | 以"睡眠+人文"重新定义中端客房，是国内创新最活跃的品牌 |
| **安缦酒店** | 全球奢华独立标杆 | 官网/品牌白皮书/行业报告 | 奢华酒店的产品定义者，"空间+隐私+在地"模型行业公认 |
| **希尔顿集团** | 国际商务型标杆 | 集团年报/品牌矩阵 | 商务客群分类最清晰，从 Hampton 到华尔道夫的商务梯度完整 |
| **锦江/华住** | 中国经济型连锁标杆 | 锦江酒店年报/华住集团年报 | 经济型客房的标准化定义者，"干净+基本"的底线模型 |

### 2.2 标杆客房产品拆解

#### 万豪国际：品牌梯度矩阵

万豪的核心逻辑是"同一集团内，品牌=客群身份=产品承诺"。

| 品牌层级 | 代表品牌 | 客房面积 | 核心产品特征 | 服务承诺 | 价格区间（一线） |
|----------|----------|----------|-------------|----------|-----------------|
| 经典奢华 | 丽思卡尔顿、瑞吉、JW万豪 | 45-80+㎡ | 全景+客厅+高端卫浴+管家 | 24h管家、定制化 | 2000-5000+ |
| 特色奢华 | W酒店、艾迪逊、豪华精选 | 40-70㎡ | 设计感+社交+艺术/潮流 | 潮流体验、社交空间 | 1500-4000 |
| 高级 | 万豪、喜来登、威斯汀 | 30-45㎡ | 商务+休闲平衡、天梦之床 | 商务效率+ wellness | 800-1800 |
| 精选 | 万怡、福朋喜来登、雅乐轩 | 22-32㎡ | 标准商务/年轻客群 | 基础商务+免费WiFi | 400-800 |
| 长住 | Residence Inn、万枫 | 20-60㎡ | 厨房+客厅，套房为主 | 长住设施、自助 | 300-1500 |

**万豪公约数提炼**：品牌定位决定客群身份，服务承诺决定人房交互深度，忠诚度权益改变同一客房的体验。

#### 亚朵集团：生活方式细分

亚朵是国内第一个把客房产品按**生活场景**而非价格细分的品牌。

| 品牌 | 产品定位 | 核心差异 | 客房特征 | 价格区间 |
|------|----------|----------|----------|----------|
| 亚朵 | 标准中高端 | 睡眠+人文 | 普兰特床垫+属地摄影 | 350-600 |
| 亚朵S | 品质升级 | 设计+空间 | 更大面积+艺术装置 | 450-800 |
| 亚朵X | 轻中端 | 年轻+性价比 | 简洁+智能控制 | 250-450 |
| 亚朵轻居 | 轻旅居 | 年轻差旅 | 紧凑+低价 | 200-350 |
| ZHotel | 电竞/社交 | 主题场景 | 电竞设备+社交空间 | 300-500 |

**亚朵公约数提炼**：睡眠品质是核心差异（床垫分级），人文氛围是情绪价值（属地摄影/书籍），社交属性是场景延伸（大堂/共享空间）。

#### 安缦酒店：空间隐私在地

安缦不自称"酒店"，自称"retreat"。产品逻辑是**空间+在地+隐私**。

| 产品特征 | 具体做法 | 本质 |
|----------|----------|------|
| 空间尺度 | 每间房≥60㎡，套房≥100㎡，公共空间≤客房面积 | 空间即奢华 |
| 在地融入 | 当地材料+当地工匠，每店独一无二 | 不可复制性 |
| 隐私隔离 | 低密度（每店≤50间房），无大堂社交压力 | 隐私即产品 |
| 服务预判 | 无仪式感，一切在开口前完成 | 服务不是表演 |
| 无品牌标识 | 酒店外无logo，房间内无品牌露出 | 品牌是信任 |

**安缦公约数提炼**：空间稀缺性（低密度+大面积）、在地唯一性（不可复制）、服务预判（无痕迹）。

#### 希尔顿集团：商务梯度

| 品牌层级 | 代表品牌 | 核心客群 | 客房特征 | 价格区间 |
|----------|----------|----------|----------|----------|
| 奢华 | 华尔道夫、康莱德 | 高端商务+休闲 | 大空间+管家+定制 | 2000-5000+ |
| 高端 | 希尔顿、希尔顿逸林 | 标准商务+会议 | 商务设施+标准服务 | 800-1800 |
| 中端 | 希尔顿花园、希尔顿欢朋 | 性价比商务 | 标准配置+早餐 | 400-800 |
| 经济 | Hampton（欢朋） | 预算商务 | 简洁+免费早餐 | 300-500 |

**希尔顿公约数提炼**：商务客群分层最清晰（奢华/高端/中端/经济），行政效率是核心承诺，免费早餐是中端以下标配。

#### 锦江/华住：经济型底线

| 品牌 | 产品定位 | 核心承诺 | 客房标准 | 价格区间 |
|------|----------|----------|----------|----------|
| 锦江之星 | 标准经济 | 干净+安全 | 15-20㎡，基础卫浴 | 150-250 |
| 汉庭（2.7/3.0） | 经济升级 | 干净+智能 | 18-24㎡，智能控制 | 180-350 |
| 海友 | 超经济 | 睡觉即可 | 10-15㎡，公共卫浴可选 | 80-150 |

**锦江/华住公约数提炼**：底线标准（干净/安全）是产品本身，标准化可复制是信任来源，成本极限控制是价格竞争力。

### 2.3 最大公约数提炼

基于五家标杆的拆解，提炼出客房产品的**6个本质维度**和**5种创新产品类型**。

**6个本质维度（最大公约数）**：
1. 硬件设施（万豪面积矩阵+安缦空间稀缺+亚朵睡眠品质）
2. 空间位置（万豪位置全覆盖+安缦隐世+亚朵商务区）
3. 服务范围（万豪权益体系+安缦预判+希尔顿效率）
4. 价格定位（万豪动态定价+锦江成本极限+安缦一价全包）
5. 风格特征（万豪品牌矩阵+亚朵生活方式+安缦在地唯一）
6. 客群适配（万豪客群分层+亚朵情绪价值+希尔顿商务梯度）

**5种创新产品类型（最大公约数→场景导向命名）**：
- 基础客房：汉庭/锦江/万枫的公约数 → 为底线住宿场景优化
- 舒适客房：亚朵/万怡/全季的公约数 → 为常规出行场景优化
- 商务客房：万豪商务/希尔顿商务的公约数 → 为商务效率场景优化
- 豪华客房：威斯汀/W/艾美的公约数 → 为度假体验场景优化
- 套房产品：安缦/丽思卡尔顿/瑞吉的公约数 → 为长住尊享场景优化

## 三、产品分析模型（6维度，标杆蒸馏）

每个维度有标杆出处、客观数据、下一步动作。维度数量6个，经标杆验证均为本质维度，不堆砌。

### 维度1：硬件设施
**核心问题**：这间房在物理空间和硬件上提供什么？  
**标杆出处**：万豪面积矩阵（Fairfield 20㎡ vs 丽思卡尔顿 60+㎡）+ 安缦空间稀缺（≥60㎡）+ 亚朵睡眠品质（普兰特床垫分级）

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 面积 | 15-20㎡ / 20-28㎡ / 28-35㎡ / 35-50㎡ / 50㎡+ | 数值区间 | 根据客户人数和行李量判断空间需求 |
| 床型 | 单人床(1.0m) / 标准大床(1.5m) / 加大床(1.8m) / 特大床(2.0m) / 双床(1.2m×2) / 家庭多床 | 枚举 | 根据出行人数和关系判断床型需求 |
| 睡眠品质 | 经济床品 / 标准品牌 / 中高端（普兰特/金可儿） / 奢华（席梦思黑标/海丝腾） | 枚举 | 根据客户睡眠敏感度判断（商务客高敏感） |
| 景观 | 无窗 / 内景 / 城景 / 海景 / 湖景 / 花园 / 地标 / 庭院 | 枚举 | 根据出行目的判断景观权重（休闲>商务） |
| 卫浴 | 标准淋浴 / 淋浴+浴缸 / 独立干湿分离 / 双台盆+高端 / 独立桑拿/SPA | 枚举 | 根据停留时长和舒适度要求判断 |
| 特殊设施 | 阳台 / 露台 / 厨房 / 客厅分区 / 办公区 / 迷你吧 | 多选布尔 | 根据长住/家庭/商务需求判断 |

### 维度2：空间位置（新增，用户明确要求）
**核心问题**：这间房在什么位置？周边是什么环境？交通便利性如何？  
**标杆出处**：万豪位置全覆盖（机场/商务区/景区/交通枢纽）+ 安缦隐世度假（远离喧嚣）+ 亚朵商务区核心

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 城市区位 | 机场周边 / 商务区 / 景区周边 / 交通枢纽 / 居民区 / 隐世度假地 | 枚举 | 根据出行目的判断位置权重（商务→商务区，度假→景区/隐世） |
| 交通便利性 | 地铁直达 / 公交可达 / 需打车 / 需专车 / 酒店接送 | 枚举 | 根据客户交通方式和预算判断 |
| 周边配套 | 无 / 基础餐饮 / 商业综合体 / 景点 / 商务区配套 / 自然生态 | 枚举 | 根据停留时长和出行目的判断 |
| 客房朝向 | 北向（安静/冷） / 南向（采光/暖） / 东向（日出） / 西向（夕阳） / 景观朝向 | 枚举 | 根据客户作息和景观偏好判断 |
| 楼层位置 | 低层（近设施/吵） / 中层（平衡） / 高层（安静/景观） / 行政楼层（专属） | 枚举 | 根据安静需求和身份等级判断 |
| 噪声环境 | 临街（吵） / 临电梯（中等） / 内侧（安静） / 庭院（极静） | 枚举 | 根据睡眠敏感度和安静需求判断 |

### 维度3：服务范围
**核心问题**：住这间房能享受什么服务和权益？  
**标杆出处**：万豪权益体系（旅享家）+ 安缦预判服务（无痕迹）+ 希尔顿效率标准

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 服务响应 | 自助服务 / 前台标准 / 优先通道 / 24h管家 / 私人管家 | 枚举 | 根据客户时间紧迫度和消费层次判断 |
| 专属空间 | 无 / 行政酒廊 / 贵宾休息区 / 专属餐厅 / 私人会所 | 枚举 | 根据商务/休闲目的判断 |
| 早餐等级 | 无早餐 / 简餐 / 自助 / 定制 / 客房送餐 / 全餐 | 枚举 | 根据出行时段和习惯判断 |
| 礼遇权益 | 延迟退房 / 免费升房 / 欢迎礼品 / 接送机 / 熨衣 / SPA券 | 多选布尔 | 根据消费层次和会员等级判断 |
| 特殊服务 | 儿童看护 / 宠物接待 / 无障碍 / 商务秘书 / 医疗支持 | 多选布尔 | 根据特殊需求标签直接匹配 |
| 服务预判 | 无 / 基础（夜床/迎宾） / 中级（根据记录准备） / 高级（开口前完成） | 枚举 | 根据客户频次（首住/复住/常客）判断 |

### 维度4：价格定位
**核心问题**：这间房在什么价格带？性价比如何？  
**标杆出处**：万豪动态定价系统 + 锦江成本极限控制 + 安缦一价全包

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 价格区间 | 按城市等级分档（一线/新一线/二线/旅游城市）给出具体区间 | 数值区间 | 与客户预算区间直接比对 |
| 性价比评分 | 综合评分/评价数/价格的三维计算值 | 0-100分 | 在同级产品中横向比较 |
| 动态定价 | 平日价 / 周末价 / 旺季价 / 活动价 / 会员价 | 价格矩阵 | 根据入住日期匹配实时价格 |
| 附加费用透明度 | 服务费/税费/早餐/停车费是否含在房价内 | 布尔/枚举 | 对价格敏感旅客主动提示 |
| 成本结构 | 基础成本型（经济） / 体验溢价型（中高端） / 身份溢价型（奢华） | 枚举 | 根据客户价格敏感度判断 |

### 维度5：风格特征
**核心问题**：这个产品的调性是什么？给旅客什么情绪感受？  
**标杆出处**：万豪品牌矩阵（经典/潮流/wellness）+ 亚朵生活方式（人文/属地）+ 安缦在地唯一

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 调性风格 | 商务干练 / 休闲度假 / 设计艺术 / 经典传统 / 生活方式 / 隐世宁静 | 枚举 | 与客户品味倾向匹配 |
| 客群分析 | 商旅常客 / 家庭出游 / 情侣度假 / 高端休闲 / 背包客 / 生活方式追求者 / 隐私追求者 | 多选 | 与客户分析做相似度计算 |
| 标准化程度 | 全球统一复制（100%） / 品牌框架（80%） / 区域特色（50%） / 独一无二（每家不同） | 枚举 | 根据客户对确定性的需求判断 |
| 情绪价值 | 无 / 基础舒适 / 放松治愈 / 惊喜体验 / 身份认同 / 精神共鸣 | 枚举 | 根据出行目的（休闲/纪念/疗愈）判断 |

### 维度6：客群适配
**核心问题**：这个产品最适合什么类型的旅客和出行情况？  
**标杆出处**：万豪客群分层 + 希尔顿商务梯度 + 亚朵生活方式

| 子项 | 客观描述 | 数据类型 | 下一步动作 |
|------|----------|----------|------------|
| 主要客群 | 单人商旅 / 双人出行 / 家庭(带儿童) / 团队 / 长住客 / 隐私追求者 | 枚举 | 与客户出行人数直接匹配 |
| 出行目的 | 商务会议 / 标准出差 / 休闲度假 / 家庭出游 / 蜜月庆祝 / 中转停留 / 医疗陪护 / 长住生活 | 多选 | 与客户出行目的直接比对 |
| 时长适配 | 过夜(1晚) / 短期(2-3晚) / 中期(4-7晚) / 长期(7晚+) | 枚举 | 根据预订时长判断 |
| 安静倾向 | 安静(高层/庭院) / 热闹(近设施) / 社交型(近大堂) / 无所谓 | 枚举 | 根据睡眠质量和出行目的判断 |

## 四、创新产品分类体系（5类，基于标杆最大公约数）

不是复制任何一家标杆的分类，而是提炼五家标杆的最大公约数后，形成新的产品命名和定义。

### A. 基础客房（Basic Room）
**本质定位**：满足中转、过夜、临时住宿需求，价格最低，标准化可预期，成本极限控制。  
**标杆公约数**：汉庭"干净+智能" + 锦江之星"干净+安全" + 万枫"基础+标准" → 提炼出"基础客房"：为"睡一觉就走"的场景优化，不是简单的"便宜"。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 基础客房 |
| **面积** | 15-22㎡ |
| **床型** | 标准大床(1.5m) / 标准双床(1.2m×2) |
| **睡眠品质** | 经济型床品（基础弹簧床垫，满足底线） |
| **景观** | 无窗或内景 |
| **卫浴** | 标准淋浴，紧凑布局，无浴缸 |
| **城市区位** | 交通枢纽、商务区边缘、居民区 |
| **服务范围** | 自助为主，前台基础服务，无专属权益 |
| **早餐** | 无或简餐（面包+咖啡） |
| **价格区间** | 一线城市150-350元 / 新一线100-280元 / 二线80-220元 |
| **调性** | 简洁实用、无设计感、标准化可预期 |
| **适配客户** | 预算敏感旅客、中转停留、学生/背包客、短期过夜、考试/面试 |
| **出行目的** | 中转停留、过夜、最低预算出行、紧急临时住宿 |
| **核心卖点** | 价格低、干净、安全、可预期（每家店一模一样） |
| **主要短板** | 空间小、睡眠品质一般、无景观、服务简单、无情绪价值 |
| **标杆出处** | 汉庭2.7（智能底线）、锦江之星（安全底线）、万枫（国际品牌基础款） |
| **创新点** | 命名"基础客房"而非"经济"，强调即使在极限成本下仍有居住尊严；引入"可预期性"作为产品价值 |

### B. 舒适客房（Comfortable Room）
**本质定位**：满足常规出行需求，在睡眠品质、服务标准、情绪价值之间取得平衡。  
**标杆公约数**：亚朵"睡眠+人文" + 万怡"标准商务" + 全季"东方美学" → 提炼出"舒适客房"：不是某一单项最强，是多项都不弱。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 舒适客房 |
| **面积** | 22-30㎡ |
| **床型** | 加大床(1.8m) / 品质双床(1.2m×2) |
| **睡眠品质** | 中高端品牌床品（普兰特/金可儿级别，核心卖点） |
| **景观** | 标准城景或普通窗景 |
| **卫浴** | 淋浴+浴缸可选，品牌洗浴用品 |
| **城市区位** | 商务区核心、商业综合体周边、景区入口 |
| **服务范围** | 标准服务，延迟退房至14:00，属地早餐 |
| **早餐** | 自助早餐（含属地特色） |
| **价格区间** | 一线城市350-600元 / 新一线280-500元 / 二线220-400元 |
| **调性** | 生活方式、人文氛围、属地特色、温暖感 |
| **适配客户** | 常规商旅、家庭休闲、标准出游、情侣出行、品质敏感者、生活方式追求者 |
| **出行目的** | 标准出差、周末休闲、家庭短途游、常规度假 |
| **核心卖点** | 睡眠品质有保障、空间适中、有早餐、情绪价值（属地人文）、品牌可信 |
| **主要短板** | 无专属服务、无特殊景观、商务效率一般、无服务预判 |
| **标杆出处** | 亚朵（睡眠+人文核心）、万怡（标准商务）、全季（东方美学舒适） |
| **创新点** | 命名"舒适客房"而非"标准"，强调睡眠品质是核心差异；引入"属地人文"作为情绪价值来源，不是简单的"中端" |

### C. 商务客房（Business Room）
**本质定位**：满足商务出行效率需求，时间敏感、服务预判、行政支持是核心。  
**标杆公约数**：万豪"商务效率+行政酒廊" + 希尔顿"商务梯度+快速服务" + 亚朵S"品质升级" → 提炼出"商务客房"：商务核心不是"豪华"是"不浪费时间"。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 商务客房 |
| **面积** | 28-40㎡ |
| **床型** | 加大床(1.8m) / 双床(1.2m×2) |
| **睡眠品质** | 中高端品牌床品+商务助眠配置（遮光/降噪/助眠香氛） |
| **景观** | 优选城景或安静朝向（远离电梯/高楼层） |
| **卫浴** | 独立干湿分离，标准淋浴+浴缸 |
| **城市区位** | 商务区核心、会展中心、机场商务楼 |
| **服务范围** | 快速入住/退房、行政酒廊、24h响应、商务秘书、基础服务预判 |
| **早餐** | 自助+定制（可打包、快速通道） |
| **价格区间** | 一线城市600-1200元 / 新一线500-900元 / 二线400-700元 |
| **调性** | 商务干练、效率优先、专业感、时间敏感 |
| **适配客户** | 商务出差、会议接待、高频商旅、企业协议客户、效率优先者 |
| **出行目的** | 商务会议、标准出差、项目驻场、客户接待、紧急商务 |
| **核心卖点** | 效率优先、安静、办公便利、行政酒廊、商务服务、积分累计、服务预判 |
| **主要短板** | 价格偏高、休闲属性弱、家庭设施少、情绪价值低 |
| **标杆出处** | 万豪万豪/喜来登（商务全能）、希尔顿希尔顿（商务标准）、亚朵S（品质商务） |
| **创新点** | 命名"商务客房"而非"商务"，强调时间价值>空间价值；引入"服务预判"作为核心差异（根据入住记录提前准备） |

### D. 豪华客房（Deluxe Room）
**本质定位**：满足品质追求和度假体验，景观+设计+情绪沉浸是核心，让旅客"进入另一个世界"。  
**标杆公约数**：威斯汀"天梦之床+wellness" + W酒店"设计+社交+惊喜" + 艾美"艺术+探索" → 提炼出"豪华客房"：不是"豪华"是"让人忘记日常"。

| 产品卡片 | 内容 |
|----------|------|
| **产品名称** | 豪华客房 |
| **面积** | 35-55㎡ |
| **床型** | 特大床(2.0m) / 加大双床(1.35m×2) |
| **睡眠品质** | 奢华品牌床品（席梦思黑标/海丝腾级别）+定制枕头菜单+助眠方案 |

| **卫浴** | 高端卫浴品牌、独立浴缸+独立淋浴、双台盆 |
| **城市区位** | 景区核心、海滨/湖畔、城市地标、艺术区 |
| **服务范围** | 专属管家、优先通道、礼宾服务、中级服务预判、定制体验 |
| **早餐** | 定制早餐或客房送餐（可指定时间/地点/主题） |
| **价格区间** | 一线城市1200-2500元 / 新一线900-1800元 / 二线700-1400元 |
| **调性** | 设计艺术、潮流体验、 wellness、惊喜感、情绪沉浸 |
| **适配客户** | 高端商务、度假休闲、纪念日情侣、品质追求者、生活方式追求者、社交需求者 |
| **出行目的** | 高端商务、度假休闲、蜜月旅行、纪念日庆祝、品质出游、社交需求 |
| **核心卖点** | 景观佳、空间大、卫浴高端、服务专属、情绪价值（设计/艺术/香氛/wellness）、品牌溢价 |
| **主要短板** | 价格高、性价比低、商务效率未必最优、标准化程度低 |
| **标杆出处** | 威斯汀（天梦之床+wellness）、W酒店（设计+社交）、艾美（艺术+探索） |
| **创新点** | 命名"豪华客房"而非"豪华"，强调体验沉浸>物质堆砌；引入"wellness"和"艺术"作为情绪价值来源，不是简单的"贵" |

### E. 套房产品（Suite Product）
**本质定位**：满足空间多样化、隐私保护和尊享体验，是旅客的"私人领域"。  
**标杆公约数**：安缦"空间+隐私+在地+预判" + 丽思卡尔顿"管家+定制" + 瑞吉"仪式+传承" → 提炼出"套房产品"：最高层级不是"套房"是"属于你的空间"。

| **景观** | 最佳景观位（顶层/角落/全景/私人庭院/私人泳池） |
| **卫浴** | 双台盆+独立浴缸+独立淋浴，桑拿/SPA/私人泳池可选 |

| **服务范围** | 私人管家、全套行政礼遇、高级服务预判（开口前完成）、接送机、在地体验定制 |
| **早餐** | 全餐服务（客房用餐/餐厅包厢/私人厨师/野餐定制） |
| **价格区间** | 一线城市2500-8000+元 / 新一线2000-6000+元 / 二线1500-4000+元 |
| **调性** | 隐世宁静、在地唯一、身份象征、精神共鸣、无品牌压力 |
| **适配客户** | 家庭长住、高端商务、VIP接待、特殊庆祝、名人/高管、隐私追求者 |
| **出行目的** | 家庭长住(7晚+)、高端商务接待、婚礼/蜜月、VIP接待、特殊庆祝、隐世度假、疗愈休养 |
| **核心卖点** | 空间多样、私密性强、全服务覆盖、身份象征、长住便利、在地唯一、高级预判、精神共鸣 |

| **标杆出处** | 安缦（空间+在地+隐私）、丽思卡尔顿（管家+定制）、瑞吉（仪式+传承） |
| **创新点** | 命名"套房产品"而非"套房"，强调隐私和空间主权>面积大小；引入"在地唯一性"和"精神共鸣"作为最高层级价值 |

## 六、自动匹配动作模型

### 6.1 动作定义

| 字段 | 定义 |
|------|------|
| **动作名称** | 客房产品自动匹配（创新产品版） |
| **触发条件** | 客户输入分析（或系统获取分析）包含：消费水平、出行目的、人数、天数、特殊需求中的至少3项 |
| **服务对象** | 酒店客户（获得推荐）、酒店前台员工（执行推荐）、酒店经营者（查看匹配数据） |
| **执行角色** | AI匹配引擎（产品推荐助理） |
| **验收角色** | 酒店前台员工（最终确认）、酒店客户（选择下单） |

### 6.2 执行步骤

| 步骤 | 动作 | 输入 | 输出 | 异常处理 |
|------|------|------|------|----------|
| 1 | 提取客户分析 | 客户信息原始数据 | 结构化分析结果（6维度匹配值） | 数据缺失>2项 → 请求补充关键信息 |
| 2 | 初筛产品池 | 特征向量 + 全量产品库 | 符合硬性条件的产品子集 | 无匹配产品 → 扩大价格区间20% |
| 3 | 多维评分 | 产品子集 + 特征向量 | 每款产品匹配度评分（0-100）+ 维度得分明细 | 评分差距<5分 → 增加权重维度 |
| 4 | 创新产品映射 | 评分结果 | 将评分映射到5类创新产品命名 | 无明确映射 → 标记"跨类型需求" |
| 5 | 生成推荐排序 | 评分+创新映射 | Top 3推荐列表 + 创新产品名称 + 匹配理由 | 评分均<60分 → 输出"无理想匹配" |
| 6 | 服务预判提示 | 推荐结果 | 针对前台/客房员工的服务执行提示 | — |
| 7 | 输出推荐 | 完整推荐包 | 产品卡片 + 匹配理由 + 服务预判 + 风险提示 | 目标产品无房 → 推荐同级替代 |

### 6.3 匹配规则（核心规律）

| 客户特征 | 优先匹配产品 | 匹配理由 | 服务预判提示 |
|----------|-------------|----------|-------------|
| 预算<350元/晚 + 单人 + 1-2晚 | 基础客房(A) | 满足底线住宿，价格最低，可预期 | 前台：快速办理，无需额外介绍 |
| 预算350-600元/晚 + 双人 + 标准出差 | 舒适客房(B) | 睡眠品质有保障，性价比最高 | 前台：强调床垫品牌，属地早餐特色 |
| 预算600-1200元/晚 + 商务 + 时间紧迫 | 商务客房(C) | 效率优先，行政酒廊，服务预判 | 前台：提前准备快速入住，行政酒廊指引 |
| 预算1200+元/晚 + 休闲/纪念日 + 景观要求 | 豪华客房(D) | 体验沉浸，景观佳，情绪价值高 | 前台：管家提前联系，定制体验介绍 |
| 家庭4人 + 长住5晚+ + 预算2500+ | 套房产品(E) | 空间分区，厨房便利，全服务 | 前台：私人管家对接，长住服务方案 |

### 自然语言输出设计原则

| 原则 | 说明 | 为什么重要 |
|------|------|------------|
| **客户视角第一** | 客观描述产品能解决的实际问题，不说"我们酒店有"而说"你能得到什么" | 客户关心的是自己的需求，不是酒店的功能清单 |
| **痛点前置** | 直接指出客户的处境（"凌晨到达转机""带孩子住7天"），产品如何对应解决 | 让客户感受到"匹配"而非"推销" |
| **维度自然融入** | 不单独罗列"硬件设施：20㎡"，而是把面积、床型、位置融入产品描述 | 维度分析在后台，前台只说人话 |
| **标杆隐性引用** | 不提"我们对标万豪"，而是说"普兰特级别床垫""独立干湿分离" | 客户不需要知道万豪是谁，只需要知道"这标准可信" |
| **无客套话** | 不"您好"、不"尊敬的客户"、不"荣幸为您服务" | 客观陈述，降低信息噪音 |
| **无总结说教** | 不帮客户"算一笔账"、不说"这钱花得值" | 客户自己会判断，不需要被说服 |
| **拒绝虚词** | 不用"尊贵""奢华""非凡体验"，用具体描述（"42㎡、湖景、独立浴缸"） | 讲人话，禁用词语表要求 |

## 九、国内标杆补全（2026-06-13更新）

### 9.1 华住集团：多品牌矩阵拆解

华住是中国最大的酒店集团（按门店数），品牌矩阵覆盖经济型到高端，全季是其中端核心。

|------|------|----------|-------------|-----------------|----------|
| **汉庭** | 经济型升级 | 18-24㎡ | 干净+智能控制（汉庭3.0）+品牌床品 | 180-350 | 智能化是经济型的升级方向 |
| **全季** | 中端东方美学 | 25-32㎡ | 竹木设计+茶香+东方极简+好床垫 | 350-600 | "东方美学"是区别于亚朵的差异化路径 |
| **桔子** | 中端设计感 | 22-28㎡ | 色彩设计+年轻活力+社交大堂 | 300-500 | 设计年轻化，比全季更潮流 |

**华住公约数提炼**：
- **经济型→中端的核心升级路径**：智能化（汉庭）→东方美学（全季）→设计感（桔子）→精品度假（花间堂）
- **东方美学是华住的核心差异**：全季的茶香、竹木、极简，与亚朵的睡眠+人文、万豪的商务效率形成三足鼎立
- **花间堂的度假模型**：国内精品度假的标杆，选址在古镇/景区，产品设计融入在地文化

## 十、跨酒店对比模型（同城市多酒店横向对比）

### 10.1 模型定义

**目的**：在同一城市内，对比不同酒店的同类产品，给出最优推荐。  
**核心变化**：从"单酒店内选房型"升级到"同城市内选酒店+房型"。

**核心输入**：
- 客户分析（预算、出行目的、人数、天数、特殊需求）
- 城市酒店池（该城市所有合作酒店的基础客房/舒适客房/商务客房/豪华客房/套房产品）
- 实时房态和价格

**核心输出**：
- Top 3跨酒店推荐（酒店+产品组合）
- 横向对比理由（为什么A酒店的商务客房比B酒店的更好）
- 风险提示（房态、价格波动、位置差异）

### 10.2 跨酒店对比维度（在6维度基础上增加）

| 新增维度 | 说明 | 对比方式 |
|----------|------|----------|
| **品牌信任度** | 集团品牌 vs 独立品牌，客户历史评价 | 评分加权 |
| **位置差异** | 同城市不同区位（商务区A vs 商务区B vs 景区） | 距离+交通时间计算 |
| **价格差异** | 同产品不同酒店的价格差 | 绝对值+性价比 |
| **实时房态** | 各酒店目标产品的可用性 | 可用/满房/仅剩 |
| **客户历史** | 客户是否住过该品牌、是否有积分/会员 | 偏好加权 |
| **特殊优势** | 某酒店在特定产品上的独特卖点（如全季的东方美学 vs 亚朵的睡眠） | 标签匹配 |

### 10.3 跨酒店对比评分模型

总评分 = 产品匹配分（0-100，6维度评分） × 品牌信任系数（0.8-1.2） × 位置适配系数（0.8-1.2） × 价格竞争力系数（0.8-1.2） × 实时可用性系数（0或1）

| 系数 | 计算方式 | 说明 |
|------|----------|------|
| **品牌信任系数** | 集团品牌1.0，独立品牌0.9，客户历史好评1.1，差评0.8 | 品牌是信任基础 |
| **位置适配系数** | 距客户核心目的地每增加1公里扣0.02，上限1.2 | 位置直接影响体验 |
| **价格竞争力** | 同产品最低价=1.0，每高10%扣0.05，低于最低价=1.2 | 价格是最终决策因素 |
| **实时可用性** | 有房=1，仅剩1间=0.9，满房=0 | 可用性硬约束 |

### 10.7 三句话法（跨酒店对比）
