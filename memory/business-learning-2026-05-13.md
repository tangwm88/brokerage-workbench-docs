```
客户获客 → KYC画像 → 资产配置 → 产品推荐 → 投顾陪伴 → 组合调优 → 持续服务
```

## 三、信用交易业务（Credit Trading）

### 3.1 业务流程
```
客户准入 → 征信授信 → 合约签订 → 交易监控 → 风险预警 → 追保/平仓 → 到期处理
```

**核心环节（融资融券）**：
- **客户准入**：适当性评估、征信调查、准入审批
- **授信管理**：信用评估、额度授予、动态调整
- **交易执行**：融资买入/融券卖出、担保品管理
- **盯市监控**：维持担保比例实时监控、预警线/平仓线监控
- **风险处置**：追保通知、强制平仓、违约处置
- **到期管理**：合约展期、到期清算

**核心环节（股票质押）**：
- **项目准入**：标的管理、客户评级、额度授予
- **交易执行**：初始交易、补充质押、部分解质
- **履约管理**：逐日盯市、预警通知、风险处置
- **违约处置**：处置申报、标的卖出、资金偿付

## 五、固收投资业务（Fixed Income Investment）

```
宏观研究 → 利率分析 → 信用研究 → 组合构建 → 交易执行 → 风险监控 → 业绩归因
```

- **风险监控**：信用风险、利率风险、流动性风险、集中度风险
- **业绩归因**：收益分解、风险调整后收益分析

- 债券交易需符合银行间/交易所规则
- 信用评估涉及重大投资决策需人工确认
- 做市报价需符合监管要求
- 利率预测模型需可解释、可审计

### 5.4 智能体设计建议
- **组织者：固收投资协调官**
  - 统筹宏观/利率/信用/交易/风控全流程
  - 重点请示：大额交易决策、信用重大变化、组合大幅调整
  
- **超级数字员工**：
  - **宏观分析师**：经济数据跟踪、政策解读、流动性研判
  - **利率分析师**：收益率曲线分析、利率预测、期限结构研究
  - **信用研究员**：财报解析、主体评估、行业信用分析
  - **交易执行员**：询报价、做市、交易分析
  - **风险监控员**：信用/利率/流动性风险监控、预警
  - **业绩归因员**：收益分解、风险归因、报告生成
