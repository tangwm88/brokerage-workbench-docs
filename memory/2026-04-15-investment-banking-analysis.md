## 一、业务知识摘要

### 1.1 股权保荐与承销业务流程

根据《证券发行上市保荐业务管理办法》，股票保荐与承销业务全流程包括：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        股权保荐与承销业务流程                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐          │
│  │ 项目承揽 │───▶│ 项目立项 │───▶│ 改制辅导 │───▶│ 尽职调查 │          │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘          │
│       │                                                    │            │
│       ▼                                                    ▼            │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐          │
│  │ 持续督导 │◀───│ 发行上市 │◀───│ 监管审核 │◀───│ 内部审核 │          │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘          │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 关键业务环节详解

| 环节 | 主要工作内容 | 参与角色 | 核心交付物 |
|------|-------------|---------|-----------|
| **项目承揽** | 发掘潜在上市客户，初步尽调，签署保密协议，建立合作意向 | 承揽团队、业务部门负责人 | 合作意向书、项目备忘录 |
| **项目立项** | 立项申请、立项审查（质量控制部预审）、立项委员会审议（5名委员，4票通过） | 立项委员、质控人员 | 立项申请报告、立项决议 |
| **改制辅导** | 协助企业股份制改造，规范公司治理，辅导期不少于3个月 | 保荐代表人、项目组成员 | 辅导备案文件、辅导验收报告 |
| **尽职调查** | 财务尽调、法律尽调、业务尽调，审阅工作底稿，核查发行人披露信息 | 项目组、质控部（现场核查） | 尽职调查报告、工作底稿 |
| **内部审核** | 质量控制部初审会、内核部内核会议（2/3以上同意）、反馈意见落实 | 内核委员、风控/合规部门 | 内核意见、反馈回复 |
| **监管审核** | 向证监会/交易所报送材料，答复审核问询，配合审核检查 | 保荐代表人、发行人 | 招股说明书、审核回复 |
| **发行上市** | 路演推介、簿记建档、定价配售、资金验资、股份登记 | 资本市场部(ECM)、发行人 | 发行公告、上市公告书 |
| **持续督导** | 督导发行人规范运作，审阅信息披露文件，定期回访 | 保荐代表人 | 持续督导报告 |

#### 质量控制与风险管理

**三道防线体系**:
1. **第一道防线**: 项目组 - 尽职调查、审慎核查
2. **第二道防线**: 质量控制部 - 现场核查、底稿验收、初审会
3. **第三道防线**: 内核部/风控/合规 - 内核审议、风险监控

**关键风控节点**:
- 立项审查：设置两个立项时点（协议签署前、辅导协议签署前）
- 现场核查：IPO项目必须进行现场核查，出具现场核查报告
- 底稿验收：质量控制报告及底稿验收意见通过后方可启动内核
- 问核机制：对项目负责人进行问核，确认勤勉尽责

#### 簿记建档发行流程（核心环节）

| 步骤 | 工作内容 | 关键要求 |
|------|---------|---------|
| **发行准备** | 与发行人确认发行要素，签署《簿记利率区间确认书》，获取划款通知单 | 备案文件提前2个交易日提交交易所 |
| **信息披露** | 披露发行公告、募集说明书、申购要约、价位区间 | 公开发行：中国债券信息网+中国货币网 |
| **簿记建档** | 收集申购订单，记录申购利率/价格、数量、投资者信息 | 截止时间原则上不晚于18:00，可延时一次至19:00 |
| **定价配售** | 按利率由低到高排序，募满总额对应利率为最终利率；边际配售合理分配 | 律师事务所见证，合规/风控全程监督 |
| **发行结果** | 公告发行规模、认购倍数、最终利率，报备承销总结报告 | 上市后10个交易日内提交总结报告 |

#### 尽职调查重点关注问题

| 业务类型 | 关注要点 |
|---------|---------|
| **上市公司收购** | 收购人目的、实力、控制关系、管理经验、资信、资金来源、后续计划、履约能力、对上市公司影响 |
| **要约收购** | 要约目的、支付方式、履约能力、退市风险、中小股东保护机制 |
| **重大资产重组** | 重组目的、方案合理性、交易定价公允性、资产权属清晰性、持续盈利能力、盈利预测可实现性 |
| **发行股份购买资产** | 发行目的、标的估值公允性、资产完整性、对上市公司影响的量化分析、股份定价、中小股东权益保护 |
| **上市公司合并** | 合并目的、可行性、方案设计、估值分析、折股比例公允性、整合安排 |
| **股份回购** | 回购目的适当性、必要性、定价模式、对现金流影响、是否利于持续发展 |

#### 财务顾问核心职责

1. **尽职调查与风险评估**: 全面调查并购重组活动，评估相关风险
2. **专业服务与方案设计**: 分析法律、财务、经营风险，设计并购重组方案
3. **规范化运作辅导**: 辅导委托人熟悉法规，督促依法履行义务
4. **专业意见发表**: 客观公正发表专业意见，保证真实、准确、完整
5. **持续督导**: 督导委托人规范实施方案，办理产权过户，核查实施效果

### 2.2 高AI潜力场景分析

#### 场景一：智能尽调助手（极高潜力）

**痛点描述**:
- 尽职调查工作强度大、时间窗口紧、内容重复性高
- 需要处理大量非结构化数据（合同、财报、工商信息、舆情等）
- 底稿整理工作耗时耗力，易出错
- 项目组人员需要从"基础编写"转向"价值核验"

**AI化方案**:
1. **智能文档抽取**: 从审计报告、业务台账自动抽取关键财务数据
2. **自动底稿分类**: 基于AI的底稿自动分类、命名、归档
3. **异常风险识别**: 自动识别财务异常、法律风险、关联交易
4. **尽调清单管理**: 智能生成尽调清单，跟踪完成进度

**预期效果**:
- 底稿整理效率提升70%+
- 数据录入错误率降低90%+
- 尽调报告初稿生成时间从3天缩短至30分钟

#### 场景二：智能募集书/招股书生成（极高潜力）

**痛点描述**:
- 募集说明书/招股书编制耗时，格式要求严格
- 财务数据需要反复核对，容易出错
- 历史版本管理复杂，变更追溯困难
- 合规审查工作量大

**AI化方案**:
1. **智能章节生成**: 基于发行人材料自动填充标准章节
2. **财务数据自动填充**: 从审计报告自动提取并填入财务数据
3. **格式自动校验**: 自动检查格式、编号、交叉引用
4. **版本对比追踪**: 自动识别版本差异，生成变更说明

**预期效果**:
- 募集书编制时间缩短60%+
- 数据错误率降低80%+
- 合规审查效率提升50%

#### 场景三：簿记建档智能助手（极高潜力）

**痛点描述**:
- 簿记建档时间窗口紧（通常只有一天）
- 申购数据量大，需要实时处理
- 定价决策需要综合考虑多维度因素
- 合规要求严格，需全程留痕

**AI化方案**:
1. **智能询价分析**: 汇总历史询价数据，预测最优利率区间
2. **申购实时监控**: 实时汇总申购订单，生成需求曲线
3. **定价辅助决策**: 基于市场数据、投资者结构推荐定价方案
4. **配售方案优化**: 根据预设规则自动生成分配方案
5. **合规自动检查**: 自动检查投资者资质、配售合规性

**预期效果**:
- 簿记建档效率提升40%+
- 定价准确性提升
- 合规风险降低

#### 场景四：智能合规风控（高潜力）

**痛点描述**:
- 投行项目多，合规风险点分散
- 利益冲突审查工作量大
- 内幕信息知情人管理复杂
- 持续督导任务繁重

**AI化方案**:
1. **利益冲突自动比对**: 自动识别项目间的利益冲突
2. **内幕信息知情人监控**: 自动跟踪知情人交易行为
3. **舆情风险预警**: 实时监控发行人舆情，预警负面信息
4. **持续督导任务提醒**: 自动生成督导任务清单，提醒关键节点

**预期效果**:
- 合规审查效率提升50%+
- 风险事件发现时间提前
- 督导任务遗漏率降低90%

#### 场景五：项目筛选与承揽助手（高潜力）

**痛点描述**:
- 潜在项目信息分散，筛选效率低
- 客户画像不完整，难以精准营销
- 行业趋势判断依赖个人经验

**AI化方案**:
1. **智能项目筛选**: 基于多维度指标自动筛选高潜力项目
2. **客户画像生成**: 整合工商、舆情、财务数据生成客户画像
3. **可比公司分析**: 自动匹配可比公司，生成对标分析
4. **行业趋势预测**: 基于大数据预测行业并购重组趋势

**预期效果**:
- 项目筛选效率提升60%+
- 客户画像准确度提升
- 承揽成功率提升

### 3.2 角色设计

```yaml
角色: 投行协调官
目标: 统筹投资银行各类业务项目执行，协调各超级数字员工协作，确保项目质量与合规
```

## 四、合规与风险考量

### 4.1 监管要求映射

| 监管要求 | AI化应对措施 |
|---------|-------------|
| **保荐机构勤勉尽责** | AI仅作为辅助工具，最终判断由保荐代表人作出 |
| **信息披露真实准确** | AI生成内容需人工核验，关键数据双重校验 |
| **尽职调查充分性** | AI辅助收集资料，项目组仍需实地核查、访谈 |
| **工作底稿完整性** | AI辅助底稿分类，但底稿内容需项目组确认 |
| **利益冲突隔离** | AI自动识别并预警，人工确认后执行隔离措施 |
| **内幕信息保密** | AI监控知情人交易，异常情况实时预警 |

### 4.2 Human-in-the-loop设计

```
关键决策点人工确认机制:

项目立项 ──▶ AI辅助评估 ──▶【人工】立项委员会审议 ──▶ 立项通过
              │
尽职调查 ──▶ AI生成初稿 ──▶【人工】项目组实地核查 ──▶ 尽调报告
              │
申报材料 ──▶ AI填充数据 ──▶【人工】保荐代表人审核 ──▶ 材料申报
              │
定价决策 ──▶ AI辅助分析 ──▶【人工】定价委员会决策 ──▶ 发行定价
              │
持续督导 ──▶ AI预警风险 ──▶【人工】督导人员核实 ──▶ 督导报告
```

### 4.3 数据安全与合规

| 数据类型 | 处理方式 |
|---------|---------|
| 发行人财务数据 | 加密存储，脱敏处理，访问权限控制 |
| 尽调底稿 | 分级授权，操作留痕，定期备份 |
| 内幕信息 | 严格访问控制，知情人登记，异常监控 |
| 客户敏感信息 | 数据脱敏，最小化使用，合规审查 |
