# 机构经纪业务智能体建模方案修改建议

> 基于华创证券机构业务制度文件的建模方案评审与修改建议
> 评审日期：2026-03-11
> 制度文件来源：/参考资料/制度规范/

## 一、总体评估结论

### 1.1 符合度评分

| 模块 | 当前符合度 | 主要差距 | 修改优先级 |
|------|-----------|---------|-----------|
| 引入客户模块 | 60% | 缺少PB专员体系、尽调流程、预沟通机制 | 🔴 高 |
| 账户开立模块 | 65% | 缺少TradeX/FixStation细分、现场尽调、程序化交易 | 🔴 高 |
| 交易服务模块 | 70% | 异常监控与制度要求不完全匹配 | 🟡 中 |
| 客户服务模块 | 75% | 基本满足，需补充回访记录与SLA | 🟡 中 |

### 1.2 核心差距总结

**与制度文件相比，现有建模方案缺少以下关键要素：**

1. **组织架构映射**：未体现PB专员、机构经纪业务办公室等关键角色
2. **尽调体系**：缺少双人尽调、尽调底稿、现场影像采集等数据模型
3. **预沟通机制**：制度要求预沟通成功后才能继续，建模中未体现
4. **司务流程**：合同签订需走司务申请流程，建模中未体现
5. **IP/MAC报备**：投资交易系统开户需报备IP/MAC，建模中未体现
6. **程序化交易**：程序化交易报告管理未在建模中体现
7. **回访监控**：异常交易需当天分析、2日内回访、5日内提交流程，建模不完整

### 2.3 业务规则调整

#### 2.3.1 线索分配规则修改

```yaml
# 原规则：所有员工可分配线索
# 修改为：仅PB专员可分配机构经纪业务线索

线索分配规则 V2.0:
  
  准入条件:
    - 员工.is_pb_specialist = 1  # 必须是PB专员
    - 员工.pb_cert_status = 1     # PB专员资格有效
    - 员工.can_initiate_process = 1  # 可发起申报流程
    
  分配流程:
    1. 线索录入:
       - 来源类型为"机构业务"的线索
       - 仅可分配给PB专员
       
    2. 预沟通环节（新增）:
       - 分配后触发预沟通任务
       - PB专员需在24小时内完成预沟通
       - 预沟通结果=通过，方可进入尽调环节
       - 预沟通结果=不通过，流程终止（可申请复议）
       
    3. 尽调任务分配:
       - 预沟通通过后生成尽调任务
       - 指派双人尽调团队
       - 生成尽调报告编号
```
