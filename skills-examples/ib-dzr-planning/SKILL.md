# 投行定增业务方案设计

指导 AI 完成定向增发（Private Placement / 定增）业务方案的系统性设计，
确保方案符合监管规则、具备市场可行性、满足发行人与投资者双方诉求。

## 定增业务核心定义

**定向增发**指上市公司向符合条件的少数特定投资者非公开发行股份的行为。
在中国 A 股市场，主要适用《上市公司证券发行管理办法》《创业板上市公司证券发行注册管理办法》等规则。

**关键要素**：
- 发行对象：不超过35名特定对象（主板）
- 定价基准：不低于定价基准日前20/60/120个交易日均价的80%
- 锁定期：6个月（普通投资者）/ 18个月（控股股东/实际控制人/战略投资者）
- 募集资金：需有明确用途，符合产业政策

## 核心工作流

```
1. 项目画像与可行性初判
   └─ 发行人基本面扫描 → 融资必要性评估 → 监管红线排查

2. 定增方案框架设计
   └─ 发行规模测算 → 定价策略制定 → 募集资金用途规划 → 发行对象画像

3. 市场可比与定价验证
   └─ 同类案例检索 → 折价率分析 → 市场情绪评估 → 定价区间测算

4. 合规边界审查
   └─ 发行条件核查 → 募集资金投向合规 → 发行对象适格性 → 锁定期匹配

5. 方案输出与风险揭示
   └─ 方案摘要生成 → 风险提示清单 → 后续申报路径建议
```

## 第一阶段：项目画像与可行性初判

### 发行人基本面扫描

需采集或确认的关键信息：

| 维度 | 具体内容 | 数据来源 |
|------|----------|----------|
| 公司概况 | 行业分类、主营业务、上市板块、总市值 | 公开信息 |
| 股权结构 | 控股股东/实际控制人持股比例、股权集中度 | 定期报告 |
| 财务状况 | 近3年营收/净利润、资产负债率、经营性现金流 | 年报/季报 |
| 融资历史 | 近5年再融资记录（定增、配股、可转债等） | 公告检索 |
| 股价表现 | 近1年股价走势、市盈率、市净率 | 行情数据 |
| 合规记录 | 近3年行政处罚、监管关注函、立案调查 | 监管公示 |

### 融资必要性评估（AI辅助判断框架）

**支持融资的信号**：
- 资产负债率高于行业均值，有降杠杆需求
- 募投项目与主业高度相关，符合国家产业政策导向
- 前次募集资金使用规范，披露充分
- 行业处于扩张期，需要资本支持产能/研发

**谨慎信号（需进一步说明）**：
- 账上货币资金充裕但无明确投向
- 募投项目为财务性投资（如单纯补流/偿还贷款占比过高）
- 前次募资使用进度低或变更频繁
- 股价处于历史低位，发行折价压力大

### 监管红线排查清单

AI 必须逐项核查以下禁止性条件：

- [ ] 最近三年是否被证监会立案调查
- [ ] 最近三年是否存在严重损害投资者合法权益或社会公共利益的情形
- [ ] 控股股东/实际控制人是否被立案调查或存在重大失信
- [ ] 本次发行是否会导致控制权发生变更（如适用）
- [ ] 募集资金是否投向禁止类行业（如房地产过剩产能等限制类）

> ⚠️ **合规红线**：如任一条件触发，必须在输出中**明确标红警示**，
> 并建议"暂缓启动或先完成整改后再行推进"。

## 第二阶段：定增方案框架设计

### 2.1 发行规模测算

**测算逻辑**：

```
发行规模（亿元） = MAX( 募投项目资金需求 , 资本金补充需求 , 债务偿还需求 )
              + 发行费用预留（通常为募集资金总额的1%-3%）
```

**约束条件**：
- 发行股份数量不超过发行前总股本的30%（主板规则）
- 需考虑发行后对每股收益（EPS）的摊薄影响
- 需与控股股东沟通其对持股比例稀释的容忍度

**AI 输出格式**：
```
建议发行规模：XX亿元（含发行费用）
发行上限（30%股本约束）：XX亿股
对应发行后股本摊薄：约XX%
对EPS影响测算：发行当年摊薄约XX%，次年随项目投产逐步恢复
```

### 2.2 定价策略制定

**定价方式选择**：

| 定价方式 | 适用场景 | 折价空间 | 锁定期 | 灵活性 |
|----------|----------|----------|--------|--------|
| 竞价发行 | 市场化程度高、投资者竞争充分 | 不确定 | 6个月 | 高 |
| 锁价发行 | 引入战略投资者/国资 | 可协商 | 18个月 | 低 |
| 董事会决议确定 | 实控人/关联方全额认购 | 无折价 | 18个月 | 最低 |

**定价基准日选择**：

- 选项A：董事会决议公告日（可控性强，但需提前锁定）
- 选项B：发行期首日（市场化程度高，折价不确定）

**底价测算公式**：
```
发行底价 = MAX( 定价基准日前20日均价的80% ,
                定价基准日前60日均价的80% ,
                定价基准日前120日均价的80% )
```

> **AI 操作建议**：调用行情工具获取均价数据，计算底价区间，
> 并结合当前股价与底价之间的安全边际给出建议。

### 2.3 募集资金用途规划

**用途分类与合规要求**：

| 类别 | 合规要点 | 信息披露深度 |
|------|----------|--------------|
| 项目类（产能/研发） | 需有发改委/环评批复，可行性报告 | 项目明细、投资进度、预期收益 |
| 补流/还贷 | 比例通常不超过30%，需说明合理性 | 测算依据、对财务指标改善预期 |
| 并购类 | 需说明标的估值、协同效应 | 标的尽调摘要、业绩承诺安排 |
| 研发投入 | 资本化/费用化合规，符合科创属性 | 研发项目清单、人员配置 |

**AI 输出模板**：
```
募集资金投向规划：
├─ 项目一：XX项目                       XX亿元（XX%）
│   └─ 建设周期：X年，预计IRR：XX%
├─ 项目二：XX研发中心                   XX亿元（XX%）
│   └─ 研发方向：XXX，预期专利/产出
├─ 补充流动资金/偿还贷款                XX亿元（XX%）
│   └─ 测算依据：未来X年营运资金缺口/贷款到期安排
└─ 发行费用预留                        XX亿元（XX%）
```

### 2.4 发行对象画像

**对象分类与匹配逻辑**：

| 类型 | 典型画像 | 匹配策略 | 锁定期 |
|------|----------|----------|--------|
| 控股股东/实控人 | 巩固控制权、全额认购 | 锁价发行、显示信心 | 18个月 |
| 战略投资者 | 产业协同、技术合作、渠道资源 | 引入战投条款、业绩协同 | 18个月 |
| 财务投资者 | 公募基金、保险、产业资本 | 竞价发行、市场化定价 | 6个月 |
| 员工持股计划 | 核心骨干激励 | 平价或折扣认购 | 36个月 |

**AI 辅助匹配逻辑**：
1. 识别发行人行业属性与产业链位置
2. 匹配潜在的产业战略投资者（上下游/同业整合方）
3. 评估财务投资者的参与意愿（基于折价率、公司质地、行业景气度）
4. 设计发行对象数量与单户认购额度（分散度 vs 锁定可靠性）

## 第三阶段：市场可比与定价验证

### 同类案例检索框架

AI 检索维度：
- 同行业、同市值区间近2年完成的定增案例
- 发行折价率（发行价/基准价）分布
- 发行后股价表现（1个月/3个月/6个月超额收益）
- 认购倍数（有效认购量/发行量）

### 折价率分析模板

```
可比定增案例折价率分析：
├─ 同行业近2年案例数：XX个
├─ 折价率分布：
│   ├─ 下限（10%分位）：XX%
│   ├─ 中位数：XX%
│   └─ 上限（90%分位）：XX%
├─ 市场情绪判断：低迷/中性/积极
└─ 建议定价策略：
    ├─ 保守情景：底价+XX%溢价，对应折价率XX%
    ├─ 中性情景：底价+XX%溢价，对应折价率XX%
    └─ 乐观情景：底价+XX%溢价，对应折价率XX%
```

### 定价测算工具（命令行）

```bash
# 定增底价测算
dzr-calc floor \
  --stock-code 600XXX \
  --base-date 2026-05-17 \
  --window 20,60,120 \
  --discount 0.80

# 发行摊薄测算
dzr-calc dilute \
  --shares-outstanding 1.0B \
  --new-shares 300M \
  --net-profit 500M \
  --use-proceeds-for "项目投产预期贡献利润150M/年"
```

> **注意**：上述工具为示意，实际环境中需接入行情数据源。
> AI 在无法调用实时数据时，应**明确标注为示意性测算**。

## 第四阶段：合规边界审查

### 发行条件核查清单（逐项确认）

**主板上市公司**：
- [ ] 组织机构健全、运行良好
- [ ] 盈利能力具有可持续性（最近3年连续盈利，以扣非前后孰低为准）
- [ ] 财务状况良好（最近3年及一期财务报表未被出具保留/否定/无法表示意见）
- [ ] 最近3年以现金方式累计分配的利润不少于最近3年年均可分配利润的30%
- [ ] 募集资金用途符合国家产业政策和有关环境保护、土地管理等法律
- [ ] 不存在募集资金用于持有交易性金融资产和可供出售金融资产等财务性投资情形

**创业板/科创板**：
- [ ] 适用注册管理办法，需交易所审核+证监会注册
- [ ] 对盈利要求相对宽松，但需符合板块定位（科创属性/三创四新）
- [ ] 发行价格不低于定价基准日前20个交易日均价的80%（主板同）

### 发行对象适格性核查

**禁止作为发行对象的主体**：
- 发行人控股股东/实控人控制的关联方（如参与锁价，需符合战略投资者认定）
- 最近3年受过证监会行政处罚的主体
- 因涉嫌犯罪正被司法机关立案侦查的主体

### 募集资金投向合规审查

**禁止类投向**：
- 持有交易性金融资产和可供出售的金融资产、借予他人、委托理财等财务性投资
- 直接或者间接投资于以买卖有价证券为主要业务的公司
- 改变募集资金用途未按规定程序审批

**限制类投向（需特别说明合理性）**：
- 补充流动资金比例过高（通常认为超过30%需充分论证）
- 偿还贷款但公司资产负债率明显低于行业均值

## 第五阶段：方案输出与风险揭示

### 方案摘要输出模板

```markdown
# XX公司定向增发方案设计摘要

## 一、项目概况
- 发行人：XX股份有限公司（代码：600XXX）
- 所属行业：XX行业
- 总市值：XX亿元
- 本次发行类型：向特定对象发行股票（定增）

## 二、发行方案要点
| 要素 | 设计内容 |
|------|----------|
| 发行规模 | XX亿元（不超过发行前总股本的30%） |
| 发行方式 | 竞价发行 / 锁价发行 / 董事会决议确定 |
| 定价基准日 | XX公告日 / 发行期首日 |
| 发行底价 | XX元/股（不低于定价基准日前20日均价的80%） |
| 发行对象 | 不超过35名特定对象，含战略投资者XX |
| 锁定期 | 6个月（财务投资者）/ 18个月（战略投资者/实控人） |
| 募集资金投向 | 项目类XX亿、补流XX亿、发行费用XX亿 |

## 三、定价测算
- 当前股价：XX元
- 20日均价：XX元，底价（80%）：XX元
- 60日均价：XX元，底价（80%）：XX元
- 120日均价：XX元，底价（80%）：XX元
- 建议发行价区间：XX元 ~ XX元（对应折价率XX%~XX%）

## 四、摊薄影响
- 发行前总股本：XX亿股
- 拟发行股数：XX亿股（摊薄XX%）
- 发行后总股本：XX亿股
- 对EPS影响：发行当年摊薄约XX%，次年随项目投产逐步恢复

## 五、风险提示
1. **市场风险**：发行期间股价波动可能导致折价率偏离预期
2. **监管风险**：交易所审核/证监会注册存在不确定性
3. **认购风险**：市场低迷时可能出现认购不足或发行失败
4. **股价表现风险**：发行后6-18个月内股价可能低于发行价
5. **募投项目风险**：项目进度、收益不及预期
6. **合规风险**：如隐瞒关联关系或虚假陈述，存在被监管处罚风险

## 六、申报路径建议
- 适用板块：主板 / 创业板 / 科创板
- 审核路径：董事会 → 股东大会 → 交易所审核 → 证监会注册 → 发行
- 预计周期：自董事会决议起约6-9个月（含交易所审核2-3个月、注册1个月）
- 关键节点：XX年XX月董事会、XX年XX月股东大会、XX年XX月申报交易所
```

### 风险揭示标准话术

AI 必须在方案末尾输出**不少于5条**的风险提示，且不得使用"本方案仅供参考"等模糊免责语，
应具体指出：
- 哪些环节存在不确定性
- 不确定性的触发条件
- 最坏情景的量化影响

## 输出质量控制

### 自检清单（AI生成后自检）

- [ ] 发行底价测算是否正确（取20/60/120日均价80%的最大值）
- [ ] 发行规模是否超过30%股本上限
- [ ] 募集资金补流/还贷比例是否超过30%（如超过，是否充分论证）
- [ ] 发行对象数量是否超过35名
- [ ] 锁定期是否与发行对象类型匹配
- [ ] 募集资金投向是否涉及禁止类行业
- [ ] 风险提示是否不少于5条且具体可量化
- [ ] 是否明确标注了无法获取实时数据时的假设前提

### 禁止性输出

❌ 不得给出具体股票投资建议（如"建议买入/卖出"）
❌ 不得承诺发行成功或具体发行价格
❌ 不得在未获授权情况下引用具体客户敏感信息
❌ 不得在监管红线触发时仍输出"可以继续推进"
❌ 不得使用未经核实的市场传闻作为方案依据

## 人机协作界面

**AI 辅助边界**：
- ✅ 可以做的：方案框架生成、定价测算、可比分析、合规初筛、材料模板输出
- ⛔ 不可做的：最终定价决策、发行对象确定、监管沟通、替代保荐机构的尽调职责

**人工确认节点**：
1. 方案框架初稿生成后 → 投行项目组审核并补充客户特定信息
2. 定价区间测算后 → 与发行人沟通确认发行底价与预期区间
3. 合规红线排查后 → 如触发警示，由合规部出具书面意见
4. 最终方案输出前 → 保荐代表人签字确认
