## 一、资产管理（产品销售、产品创设）

### 1.1 业务知识摘要

**业务流程全景**：
```
产品创设 → 准入审核 → 募集发行 → 存续管理 → 终止清算
   ↑___________________________________________↓
              渠道协同销售（银行/券商/第三方）
```

**核心环节**：
- **产品创设**：券商资管、私募、场内ETF、报价回购、逆回购、信托计划等多元产品设计与报批
- **准入审核**：产品合规性审查、风险等级评定、适当性匹配
- **募集发行**：多渠道协同（银行、券商、第三方销售）、统一管控
- **存续监控**：产品净值跟踪、风险预警、合规披露
- **终止清算**：产品到期/提前终止处理、资金清算分配

**行业实践**：
- 顶点软件资管综合运营平台：覆盖银行理财、信托、公募基金等全品类资管产品全生命周期，实现跨系统运营打通、自动化监管数据生成
- TAMP（全托资产管理平台）：搭载LLM智能投顾助手，赋能投资顾问开展资产配置
- 买方投顾转型：从"以产品销售为核心"转向"以客户为中心的买方投顾"综合服务模式

### 1.2 AI化机会分析

| 场景 | AI化动作 | 底座调用 | 预期效果 |
|------|----------|----------|----------|
| 智能产品创设 | 基于市场需求和监管规则自动生成产品方案草案 | 统一语料（监管规则库）、关系网络 | 产品创设周期缩短50%+ |
| 产品准入审核 | 自动比对监管要求、识别合规风险点、生成审核意见 | 风控规则标准、统一语料 | 审核效率提升60%+ |
| 客户画像与产品匹配 | 基于客户AUM、风险偏好、交易行为推荐适配产品 | 机构账户关联、AI标签画像 | 产品转化率提升20%+ |
| 智能投顾陪伴 | LLM驱动的资产配置建议、持仓诊断、调仓提醒 | 统一语料（市场数据）、知识库 | 人均服务客户数提升25%+ |
| 存续期合规监控 | 自动监测产品净值异常、生成监管报送材料 | 风控规则标准、关系网络 | 合规成本降低40%+ |
| 渠道协同管理 | AI分析各渠道销售绩效、预测产品需求、优化分配 | 统一语料、关系网络 | 渠道效率提升30%+ |

### 1.3 智能体设计建议

**组织者：资管协调官**
- 统筹产品创设、准入、募集、存续、清算全流程
- 协调各超级数字员工协作
- **重点事项请示**：重大产品创设决策、跨渠道资源协调、监管新规应对

**超级数字员工**：
- **产品创设员**：产品设计草案生成、要素合规检查、申报材料准备
- **准入审核员**：监管规则比对、风险等级评定、适当性匹配验证
- **渠道管理员**：渠道绩效分析、需求预测、资源优化分配
- **投顾助手**：客户画像分析、资产配置建议、持仓诊断报告
- **合规监控员**：存续期风险监测、监管报送生成、异常预警

**合规边界**：
- 产品推荐需人工最终确认（适当性管理要求）
- 投资决策不可完全由AI自主执行
- 监管报送材料需人工复核签章

## 二、债券销售交易

### 2.1 业务知识摘要

**业务流程全景**：
```
项目承揽 → 尽职调查 → 材料制作（募集书） → 簿记建档 → 发行定价 → 存续期管理
    ↑                                              ↓
    └──────────── 做市报价 / 交易执行 ──────────────┘
```

**核心环节**：
- **债券承销**：项目承揽、发行人尽职调查、募集说明书编制、簿记建档、定价配售
- **做市业务**：双边报价、库存管理、风险敞口控制
- **交易执行**：指令接收、算法交易、成交确认、结算交收
- **存续期管理**：付息兑付提醒、信息披露督导、风险监测预警

**行业实践**：
- 东吴证券提出AI在债券承销的五大应用：NLP+OCR尽调文档解析、知识图谱主体关联识别、可解释AI风控合规、强化学习利率区间计算、联邦学习共享模型参数
- 智能募集书生成：AI自动抽取审计报告财务数据，依据披露规则一键生成募集说明书财务相关内容
- 智能簿记：AI实时分析订单流，识别投资者投标模式，动态预测总认购倍数
- 华泰FICC：大象大交易平台（HEADS）、CAMS信用分析管理系统
- 中金：衍生品做市系统、跨市场跨产品固收投资系统

### 2.2 AI化机会分析

| 场景 | AI化动作 | 底座调用 | 预期效果 |

| 智能尽调 | NLP+OCR自动解析募集书/财报/合同，抽取关键条款要素 | 统一语料（工商/裁判/舆情）、关系网络 | 尽调效率提升70%+ |
| 募集书生成 | 自动抽取财务数据，按披露规则生成募集说明书初稿 | 统一语料、风控规则标准 | 编制时间缩短60%+ |
| 智能簿记 | 实时分析订单流、识别投资者模式、预测认购倍数 | 机构账户关联、统一语料 | 簿记效率提升40%+ |

- **重点事项请示**：重大发行定价决策、做市风险敞口超限、异常交易事件

## 三、财富管理

### 3.1 业务知识摘要

**业务流程全景**：
```
客户获取 → 风险测评 → 资产配置 → 产品推荐 → 交易执行 → 持续陪伴 → 再平衡
    ↑                                                            ↓
    └────────────────── 账户诊断 / 投教服务 ──────────────────────┘
```

**核心环节**：
- **客户获取与分层**：线上获客、客户画像、分层服务（大众/富裕/高净值）
- **风险测评与适当性管理**：KYC问卷、风险承受能力评估、产品适当性匹配

- **产品推荐**：买方投顾模式下的个性化产品推荐
- **持续陪伴**：账户诊断、持仓分析、调仓建议、投教内容推送
- **合规管理**：投顾服务合规、产品推荐留痕、投诉处理

**行业实践**：
- 华泰AI涨乐APP：自然语言交互核心，语音下单、智能选股、资产配置、市场解读，"一句话交易、一句话投顾"

- 招商招小顾：财富顾问人均服务客户数提升25%
- 广发易小淘：AI投资助理累计使用超1000万次
- 顶点软件C6平台：客户标签、客户服务、AUM分析、合规管理、知识库

## 四、信用交易（融资融券、股票质押）

### 4.1 业务知识摘要

**业务流程全景**：
```
客户准入 → 授信审批 → 担保品管理 → 交易监控 → 风险预警 → 强制平仓/追保
    ↑              ↓
    └──── 两融助手 / 风险智能中枢 ─────┘
```

**核心环节**：
- **客户准入**：资质审核、征信查询、风险测评

- **担保品管理**：标的池维护、折算率调整、集中度监控
- **交易监控**：维持担保比例实时计算、预警线/平仓线监控
- **风险预警**：账户风险分级、追保通知、强制平仓执行
- **股票质押**：标的选择、质押率设定、贷后管理

**行业实践**：

- 国金证券：智能风险中枢新增100+核心风险因子，多维舆情风险实时监测

    ↑                                                            ↓

### 6.1 业务知识摘要

```
宏观研究 → 利率分析 → 信用研究 → 券种筛选 → 投资决策 → 交易执行 → 风险监控
    ↑                                                            ↓
    └────────── CAMS / 固收+智能体 ──────────┘
```

**核心环节**：
- **宏观研究**：货币政策、财政政策、经济数据跟踪分析
- **利率分析**：收益率曲线、久期管理、利差分析
- **信用研究**：主体信用评级、行业信用利差、违约风险预测
- **券种筛选**：基于策略目标筛选个券、构建组合
- **交易执行**：指令下达、做市报价、成交确认
- **风险监控**：组合久期、凸性、信用敞口、流动性风险监控

- 华泰FICC：大象大交易平台（HEADS）、CAMS信用分析管理系统

- 东吴证券：债券精准定价与自动化交易、AI情绪分析预判市场反应
- 国泰海通：FICC风控平台嵌入AI功能，跨市场跨资产风险实时计量

## 八、实施建议与风险提示

### 8.1 分业务线优先级建议

| 优先级 | 业务线 | 理由 | 推荐首场景 |
|--------|--------|------|-----------|
| P0 | 研究所 | 数据密集、规则明确、效果易量化 | 智能纪要+日报自动生成 |
| P0 | 财富管理 | 客户感知强、同业已验证、ROI清晰 | AI投顾陪伴 |
| P1 | 信用交易 | 风险监控刚需、数据标准化程度高 | 实时风险预警 |
| P1 | 债券销售交易 | 文档处理量大、簿记压力大 | 智能募集书生成 |
| P2 | 固收投资 | 专业性高、模型依赖度大 | CAMS信用分析 |
| P2 | 资产管理 | 产品生命周期长、合规要求高 | 产品准入审核 |

### 8.2 关键风险提示

1. **AI幻觉风险**：投研/投资决策场景需严格人工复核，建议引入多模型交叉验证机制
2. **数据安全合规**：客户敏感数据需脱敏/加密，符合《网络安全法》大修后要求
3. **监管科技升级**：证监会明确"强化财务舞弊监管AI大模型应用"，券商AI系统可审计性成为硬要求
4. **五部门拟人化新规**（2026-04-24）：AI对外服务需安全评估与备案，需建立分级分类监管台账
5. **仅2%企业实现规模化部署**：技术架构、协议标准、框架选型、安全隐患是四大瓶颈

### 8.3 下一步行动建议

1. **选择P0场景快跑**：研究所智能纪要+财富管理AI投顾，2个月内推出MVP
2. **建立业务模型模板**：按"模型能力名称→主要维度→下级子模型→模型说明"统一输出格式
3. **预埋线一**：接入MCP+A2A协议栈，预留OASF能力目录接口
4. **合规前置**：建立AI应用分级分类监管台账（低/中/高三类），明确Human-in-the-loop节点
5. **效果量化**：每个场景上线前定义可量化的效率指标，上线后持续追踪
