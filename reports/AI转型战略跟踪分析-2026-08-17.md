## 二、可获取的微弱信号（GitHub Trending）

本周GitHub Trending出现多个与Agent基础设施相关的项目，可作为行业技术方向的间接信号：

### 2.1 Prime Agent — 长时自主任务智能体
- **项目**：PrimeIntellect-ai/prime-agent
- **核心能力**：
  - Recursive Language Model (RLM)：将上下文视为变量，工具调用视为递归子智能体
  - Continual Harness：持久化存储提示词、记忆、技能描述、子智能体规范
  - 后台会话：断开终端后智能体继续运行，可重新连接
  - 智能体间直接通信：运行中的智能体可互相交换消息、编排协作
  - 长任务自动推进：自动压缩、持久化目标、心跳、调度、自主模式
- **与我司对照**：
  - ✅ 方向一致：长时任务跟进是我司已识别的能力建设方向
  - ⚠️ 差距警告：Prime Agent已实现"后台运行+重新连接+智能体间通信"，我司工作台目前以单轮/短周期交互为主

### 2.2 TencentDB Agent Memory — 团队级记忆中枢
- **项目**：TencentCloud/TencentDB-Agent-Memory
- **核心能力**：
  - 将对话、文档、代码转化为四类可复用记忆资产：Chat Memory / Skill / LLM-Wiki / Code-Graph
  - 一个Proxy服务，零代码集成，无需插件/MCP Server
  - 多智能体共享同一记忆服务器
  - 核心理念："让经验积累、流动、传递给下一个智能体"
- **与我司对照**：
  - ✅ 方向一致：底座层"关系网络""公共能力池"设计理念相通
  - ⚠️ 差距警告：腾讯已推出可落地的团队级记忆基础设施，我司底座仍在设计阶段

### 2.3 Agent Skills 标准化趋势

- **信号**：Agent Skills 框架正在从大厂到社区快速标准化
